# ประวัติศาสตร์โลกบนแผนที่ · แผนช่อง

ช่องใหม่ (วางแผน 21 ต.ค. 2569) เล่าสงครามและการเดินทางที่เปลี่ยนโลก ด้วยแผนที่ดาวเทียมสไตล์ข่าว
ยังไม่มีโค้ด ไฟล์นี้คือแผนให้เริ่มทำต่อได้ทันที

## ทำไมแนวนี้
- **ไม่หมดอายุ** ต่างจากข่าวรายวัน ยอดวิวสะสมได้นาน
- **เครื่องมือมีครบ** ลูกโลก/กรอบภาพประกอบ/คน/อาวุธจาก `episodes/worldnews`, โครงคลิปยาวแบบช่วง (`Chapter`, `wf`) จาก `episodes/thaihistory/news/kit.tsx`
- **เหมาะกับแผนที่** ทุกเรื่องคือการยกทัพหรือการเดินทาง ภาพขยับตลอด
- ปลอดภัยกว่าภูมิรัฐศาสตร์ (ข้อมูลเปลี่ยนเร็ว การเมืองเปราะบาง) และภัยพิบัติ (อ่อนไหว โฆษณาจำกัด)

### ข้อห้าม (เหมือนข่าวโลก)
- ทุกกรอบภาพประกอบติดป้าย "ภาพประกอบ"
- ไม่วาดศพหรือผู้บาดเจ็บ บอกยอดสูญเสียด้วยชิปตัวเลข/ตัวนับ
- ไม่ใส่ธงหรือสัญลักษณ์นาซีบนจอ (ใช้สีกองทัพแทน) — กันโดนจำกัดโฆษณา
- ตัวเลขทุกตัวมีแหล่งใน `sources.md` พร้อมระดับความแน่นอน ถ้านักประวัติศาสตร์เถียงกัน ให้พูดเป็นช่วง ("ราว 4–6 แสน")

## สิ่งที่ต้องสร้างใหม่ (ทำครั้งเดียว ใช้ทุกตอน)
`episodes/worldhistory/kit/`
- `theme.ts` สีประจำฝ่าย (ฝ่ายบุก = แดง, ฝ่ายรับ = น้ำเงิน, กลาง = ทอง) + สีประจำช่อง
- `Army.tsx` **เส้นกองทัพแบบ Minard**: แถบหนาตามจำนวนคน ไล่ตามเส้นทาง ความหนาลดลงตามตัวเลขในแต่ละจุด — ไฮไลต์ของช่อง ใช้ได้กับทุกการยกทัพ
- `Counter.tsx` ตัวนับกำลังพลที่ลดลง/เพิ่มขึ้นติดกับหัวกองทัพ
- `Era.tsx` ป้ายปี + แถบเส้นเวลาด้านบน (ปีในเรื่องเดินไปพร้อมภาพ)
- `Borders.tsx` เส้นแดนตามยุค — แหล่งข้อมูลแนะนำ: historical-basemaps (aourednik, GeoJSON รายศตวรรษ, CC BY 4.0 ต้องเครดิตในคำบรรยายคลิป)
- `Period/` ตัวละครและของตามยุค: ทหารนโปเลียน/คอสแซค, นักรบมองโกล+ม้า, ทหาร WW2+เรือยกพล, เรือเดินสมุทร, ทหารมาซิโดเนีย

ตัวละครแต่ละยุคทำตามสไตล์ `episodes/thaihistory/news/Period*.tsx` (วาดด้วยโค้ด, โทนมืดสไตล์ข่าว)

ตัวเลขที่ต้องตรวจใน `sources.md`: กำลังพลข้ามเนมัน (Minard 422,000 / นักประวัติศาสตร์บางคนว่าเกิน 6 แสนรวมกองหนุน), ยอดกลับ (~1–4 หมื่น แล้วแต่นับ), สูญเสียโบโรดิโน, อุณหภูมิช่วงถอย

ข้อมูลที่ต้องดึง:
```bash
node scripts/fetch-imagery.mjs bluemarble eu 20 50 40 58 6000      # เนมัน–มอสโก
node scripts/fetch-imagery.mjs relief eu-relief 20 50 40 58 6000   # ภูมิประเทศ ใช้ตอนถอย
node scripts/fetch-osm.mjs ru-rivers 20 50 40 58 bigrivers          # เนมัน, ดนีเปอร์, เบเรซินา, มอสควา
```
พิกัดเส้นทาง Minard: ชุดข้อมูล Minard ที่ Tufte/R ใช้ (troops/cities/temps) ใช้ได้ตรง ๆ เป็นจุด lon/lat + จำนวนคน

## ขั้นตอนทำแต่ละตอน (ตาม `skills/map-studio/SKILL.md`)
1. `sources.md` ข้อเท็จจริง + แหล่ง + ระดับความแน่นอน
2. `script.md` + `beats.json` (`text` ให้ TTS อ่าน ตัวเลขเป็นคำ / `caption` ขึ้นจอ จำนวนคำเท่ากัน) → **ให้ผู้ใช้อนุมัติบท**
3. TTS → `align` → `node scripts/snap-words.mjs <slug>` → `timing.json`
4. ทดสอบ 10–15 วิในหน้าตาจริงก่อน (House standard ข้อ 5) → **ให้ผู้ใช้ผ่าน**
5. ทำทุกช่วง `ch0`…`ch8.tsx` ตรวจภาพนิ่งทุก ~3 วิ (ภาคต่อ: โฟลเดอร์ `epNN-2`, `epNN-3`)
6. เรนเดอร์ `--gl=angle` → `check-glitch.mjs` ต้องได้ 0 → `loudness.mjs`
7. คำบรรยาย + เครดิตแผนที่/ข้อมูล + ปก
