# สามก๊ก: ขงเบ้งยืมธนูแสนดอก (ราว 1 นาที · 16:9 และ 9:16)

ตอนก่อนศึกผาแดง ใช้สไตล์แผนที่กระดาษ S13 ชุดเดียวกับตอนผาแดง (วุย = น้ำเงิน, จ๊ก = เขียว, ง่อ = แดง)
ปม: ไม่มีเวลาทำธนู แต่รับปากไปแล้ว → คลายปม: ให้ศัตรูยิงมาให้ → พลิกครั้งที่สอง: ประวัติศาสตร์จริงไม่ใช่ขงเบ้ง
→ ชวนดูต่อ: ตอนศึกผาแดง
