# คำอธิบาย

500 คน ฝ่าวงล้อมพม่าได้ไง? 🗺️

มกราคม พ.ศ. 2310 กรุงศรีอยุธยาถูกพม่าล้อมมานานกว่าหนึ่งปี พระยาตากพาทหารไทยและจีนราว 500 คน ตีฝ่าวงล้อมออกไปในคืนเดียว คลิปนี้พาไปตามเส้นทางทีละจุดบนแผนที่ดาวเทียมจริง ตั้งแต่ค่ายวัดพิชัยจนถึงระยอง
🔥 ทำไมต้องออก: ดินปืนขาด ยิงโดยไม่ขอ และศึกวัดสังฆาวาส
🌙 คืน 3 มกราคม: ปะทะที่บ้านหันตรา และไฟลุกในกรุงตอนเที่ยงคืน
🐎 ม้า 5 ตัวที่บ้านพรานนก กับช้างจากนครนายก
💥 ศึกปากน้ำโจ้โล้: ห้ามยิงจนกว่าพม่าจะเข้ามาใกล้
🌊 เลียบชายทะเลถึงระยอง และศึกหัวสะพาน

• เส้นทาง จุดรบ และชื่อหมู่บ้านบนแผนที่เป็นแนวโดยประมาณ วางตามชื่อสถานที่ในปัจจุบัน
