# คำอธิบาย

กษัตริย์โดนยิงขา แล้วแพ้ได้ไง? 🗺️

พ.ศ. 2311 พระเจ้าตากยกทัพเรือขึ้นเหนือไปตีชุมนุมเจ้าพระยาพิษณุโลก แต่ที่ตำบลเกยไชย กระสุนนัดหนึ่งยิงถูกหน้าแข้งซ้าย จนต้องถอยทัพกลับธนบุรี คลิปนี้พาไปดูบนแผนที่ดาวเทียมจริงว่าทำไมทัพใหญ่ถึงถูกเรือลำเล็กหยุดไว้ได้
🌊 ทัพเรือหน้าน้ำ ทวนเจ้าพระยาถึงปากน้ำโพ
🛶 หลวงโกษา (ยัง) กับเรือเพรียวซุ่มยิงในทุ่งน้ำ
🎯 กระสุนที่หน้าแข้งซ้าย และการถอยทัพ
👑 คนชนะก็ไม่รอด: เจ้าพระยาพิษณุโลก และเจ้าพระฝาง
