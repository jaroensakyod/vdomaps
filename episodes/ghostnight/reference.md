## สูตรของคลิป

**โครงเรื่อง (3 นาที)**
| ช่วง | เวลา | ทำอะไร |
|---|---|---|
| Hook | 0–3 วิ | เสียงกระซิบ "ยาย…" + ตัวหนังสือเรืองเขียวคำถาม "ถ้าผีไทยทุกตน ออกมาในคืนเดียว" + ภาพคนหันหลังในแสงไฟฉาย (ฉากไคลแมกซ์ของตอนเอามาเปิด) |
| ทวน | 3–13 วิ | ชื่อตอน + สรุปตอนก่อน 2 ประโยค + ปมใหม่ (มีเสียงร้องขอให้หยุด) |
| สืบ | 13–60 วิ | "ยายเคยบอกว่า…" = กฎผีไทยของจริง → ผู้ต้องสงสัย → เดินเข้าบ้านร้าง → ใครยืนหันหลัง |
| หักมุม | ~1:00 | "แล้วเธอก็ค่อยๆ หันมา" → ไม่ใช่ยาย แต่เป็นป้าแช่ม |
| ดราม่า | 1:00–2:10 | ผีไม่ใช่ตัวร้าย คนที่ถูกผีสิงคือเหยื่อ — เลือกปกป้องแทนประจาน |
| ขยายโลก | 2:10–2:46 | ของฝากจากยาย (สมุดหน้าหาย) → ยายยังไม่ตาย → ผีตื่นทั้งประเทศ (แผนที่ไทยจุดเรืองแสง) |
| ปม + CTA | 2:46–3:09 | คอมเมนต์ลึกลับจาก "บัญชีรูปยาย" → ถามคนดูให้ทาย → "ผีตนต่อไป กำลังมา" |

**กลไกที่ทำให้ติด**
- วลีซ้ำ **"ยายเคยบอกว่า…"** (4 ครั้ง) ตามด้วยเสียงยาย = ข้อมูลความเชื่อผีไทยของจริง ทำให้เรื่องดูน่าเชื่อ และเป็นลายเซ็นของช่อง
- **ซีรีส์ผีไทยทีละตน** (ตอน 1 กระสือ…) ชื่อซีรีส์เป็นคำถาม "ถ้าวันหนึ่ง…"
- ตัวละครยุคนี้ (เพื่อนหญิงชอบไลฟ์ คอมเมนต์ มือถือ) ปะทะผีโบราณ
- ปิดท้ายด้วยคำถามที่ตอบได้สองทาง → คนดูคอมเมนต์

**ภาพ**
- การ์ตูน 2D แบนแบบเวกเตอร์ เส้นขอบดำหนา หัวโต ตาโต (สไตล์ chibi ไทยบ้านๆ) — ตัวละครเดิมใช้ซ้ำทุกฉาก
- โทนหลักมืด น้ำตาลไม้ + แสงไฟฉายเป็นกรวยสีเหลือง · ภาพความทรงจำ/คำของยายเป็น **ขาวดำ** · กลางวันสีพาสเทลสว่าง · ผีเรืองแสง **เขียวมรกต**
- เปลี่ยนภาพ ~ทุก 2–4 วิ ตามประโยค · ใช้ซูมเข้าหน้า/ปาก ตอนจุดช็อก (ปากพองแดง)
- ฉากพิเศษ: แผนที่หมู่บ้านมุมบน, หน้าจอไลฟ์ (ยอดคนดู, คอมเมนต์), แผนที่ประเทศไทยจุดเรืองแสง, การ์ดคอมเมนต์, หน้าสมุด
- ป้ายหัวข้อเล็กด้านบน (เช่น "ปากพองแดง", "ไล่ออกไม่ได้", "ปีที่แล้ว") แบบกล่องมนสีเข้ม

**ซับ**
- ล่างจอ ตัวหนาสีขาว กล่องมนสีดำ · คำสำคัญเน้นสีส้ม/ทอง และกรอบสีส้มเวลาคนอื่นพูด (ไม่ใช่ผู้เล่า)
- ทีละวลีสั้น (≤ 20 ตัวอักษร)

**เสียง**
- พากย์หลายเสียง (ผู้เล่า/ยาย/เพื่อน/ป้า) — เสียงยายเย็นกว่า ช้ากว่า
- ดนตรีหลอนเบาๆ ตลอด บิวต์ขึ้นก่อนหักมุม · SFX จริง: ประตูเอี๊ยด, กรีดร้องแว่ว, ฉีกกระดาษ, แจ้งเตือนมือถือ

## สถิติเพจ (เช็ก 27 ต.ค. 2026 จาก Chrome ที่ล็อกอิน)

เพจ "ถ้าวันหนึ่ง" — คำโปรย "เรื่องที่ไม่น่าเกิด ดันเกิดขึ้นจริงในไทย คุณจะรอดไหม? แอนิเมชันเล่าเรื่อง"
**เพจใหม่มาก**: อัปรูปโปรไฟล์ 1 วันก่อน · EP1 โพสต์ ~1 วันก่อน · EP2 ~22 ชม.ก่อน · ผู้ติดตาม 5.2K · ติดป้าย "เนื้อหาที่สร้างโดย AI" ทุกคลิป

**อ่านตัวเลข**
- EP1 ไวรัลจากศูนย์ (377K ในวันเดียว ทั้งที่มีคนติดตามไม่ถึง 6K) = Facebook ดันรีลให้คนที่ไม่ได้ติดตาม · คอนเซปต์ "ผีไทยทุกตนออกมาในคืนเดียว" แรงพอขายตัวเอง
- วิวลดลงทุกตอน (ตอนหลังเพิ่งโพสต์ด้วย แต่รูปแบบปกติของซีรีส์คือ ตอนต่อไปได้แค่คนที่ติดใจตอนก่อน) — คนดูใหม่ที่เข้ามาตอนกลางเรื่องจะงง → EP4 เริ่มใส่ "เพิ่งเจอช่องนี้? เริ่มดูตอน 1 ที่โพสต์ปักหมุด"
- % รีแอคสูงขึ้นในตอนหลัง = คนที่ตามมาเป็นแฟนจริง
- **คอมเมนต์โตตาม CTA**: EP2 "ยายพิมพ์เองไหม" (คำถามปลายเปิด) ได้ 12 · EP3 "ถ้าเป็นคุณ จะไปไหม" ได้ 54 · EP4 "พิมพ์ 1 หรือ พิมพ์ 2" + "แท็กเพื่อน" ได้ 92 → ให้ตัวเลือกพิมพ์ง่ายๆ ได้คอมเมนต์มากที่สุด
- แชร์ต่ำทุกตอน (≤0.02% ของวิว) — เรื่องแต่งต่อเนื่องคนไม่ค่อยแชร์ ต่างจากคลิปข้อมูล/ช็อกที่จบในตัว
- คอมเมนต์ส่วนใหญ่เป็นคนเล่าประสบการณ์ผีของตัวเอง (เช่น "แถวภาคกลางหมาหอนทุก 4 ปี…") — ความเชื่อพื้นบ้านจริงกระตุ้นให้คนเล่าต่อ

**แคปชันโพสต์ (สูตรเดียวกันทุกตอน)**
1. บรรทัดแรก = ภาพช็อกหนึ่งประโยค + อีโมจิ ("พ่อนั่งกินไก่ดิบอยู่ในครัวมืดทั้งคืน แล้วหันมาถามลูกว่า 'เอ็งเป็นใคร' 👁️")
2. "คืนผีตื่น ตอน N/11 · ชื่อผี"
3. เรื่องย่อ 3–4 บรรทัด จบด้วยปม
4. คำถามให้คอมเมนต์ 👇
5. "กดติดตามช่องถ้าวันหนึ่งไว้ ผีตนต่อไปกำลังมา"
6. "เรื่องแต่ง อิงความเชื่อพื้นบ้าน (ความเชื่อเรื่อง…: …)" — กันโดนรายงาน + ให้ข้อมูลจริง (EP3 เติม "อาการแบบนี้ในชีวิตจริงควรพบแพทย์")
7. แฮชแท็ก 5 ตัว: #ชื่อช่อง #ชื่อซีรีส์ #ผีไทย #ชื่อผี #เรื่องผี
