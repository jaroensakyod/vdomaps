## ตัวละครกับท่า (`src/components/Pose.tsx`)

ทุกตัวละครวาดจากโครงกระดูกแบบเดียวกัน แหล่งท่ามีสองแบบ:
- **ท่าจากโค้ด:** `runCycle` (วิ่ง), `shamble` (ซอมบี้เดินลากขา `seed` ต่างกันแต่ละตัว), `keyed` (ท่าที่กำหนดเป็นคีย์เฟรม เช่น สะดุดล้ม) → `fk()`
- **ท่าจากคลิปจริง:** `mocapPose(data, frame)` → ได้โครงกระดูกแบบเดียวกัน
แต่งตัวด้วย `LOOKS` (runner, zombieGrey, zombieOffice, zombieWorker, zombieNurse) หรือเพิ่มชุดใหม่

## รับคลิปท่าจริง

1. ถ่ายด้วยมือถือตั้งนิ่ง ถ่ายด้านข้าง เห็นทั้งตัวตั้งแต่หัวถึงเท้า พื้นหลังเรียบ แสงพอ ท่าละ 5–10 วิ
   (วิ่งหนี, หันกลับมามอง, เดินลากขาแบบซอมบี้, ยื่นแขนตะปบ, ทุบประตู) คนเดียวเล่นทุกบทได้
2. `npm run mocap -- คลิป.mp4 run1 --from 1.2 --to 4.5` → `public/mocap/run1.json`
   (MediaPipe Pose ในเบราว์เซอร์ของ Remotion ใช้การ์ดจอ ไม่ต้องลง Python ครั้งแรกจะดาวน์โหลดโมเดล ~9 MB)
3. ตรวจ: คัดลอกคลิปไว้ใน `public/mocap/` แล้วเปิด `MocapPreview` ด้วย props `{ name: "run1", src: "mocap/run1.mp4" }`
4. ใส่ในฉาก: ใน `Chase.tsx` เปลี่ยนท่าของตัวที่ต้องการ เช่น ใน `runnerAng` แทน `runCycle(f)` ด้วยท่าจากคลิป
   แล้วส่งให้ `PoseFigure` ตรงๆ: `pose={mocapPose(run1, f)}` (ข้าม `fk`) — `loop` วนท่า, `inPlace` ตัดการเคลื่อนที่ข้ามจอ
   (ฉากเป็นตัวเลื่อนตัวละครเอง), `mirror` กลับด้าน
