## สรุปสิ่งที่ต้องแก้ในบท (ไม่ได้แก้ script.md)

- **#3 night** — "และไม่หันกลับมาอีกเลย" ขัดกับ NK (ทรงหันไปมองเมือง) และขัดกับการเสด็จกลับกบิลพัสดุ์ภายหลัง → **"แต่ในคืนเดียว เขาทิ้งไปทั้งหมด ทรงม้าออกจากวังกลางดึก และไม่ย้อนกลับไปเป็นเจ้าชายอีกเลย"**
- **#16 laughcry** — ในพระไตรปิฎกไม่มีการหัวเราะ (Snp3.11 บอกแค่ดีใจแล้วน้ำตาไหล) การยิ้มมาจากอรรถกถา → เปลี่ยนการ์ดล่างเป็น **"หัวเราะแล้วร้องไห้ / ไม่ได้อยู่ฟังธรรม [ไตรปิฎก · อรรถกถา]"** (ถ้าจะให้ตรงพระไตรปิฎก ให้เปลี่ยนเสียงพากย์เป็น "ฤๅษียิ้มด้วยความยินดี แล้วน้ำตาไหล ยินดีเพราะรู้ว่า...")
- **#22 rose** — MN36 ไม่มีชื่อพิธีแรกนาขวัญ (มาจากอรรถกถา) → การ์ดล่าง **"พิธีแรกนาขวัญ / สมาธิใต้ต้นหว้า [ไตรปิฎก · อรรถกถา]"**
- **#23 marry** — อายุ 16 ไม่มีใน NK ที่ตรวจ มาจากคติไทยหรือคัมภีร์ชั้นหลัง → ถ้าจะใส่ป้าย ให้ใช้ **"อภิเษกสมรส / พระนางยโสธรา (พิมพา) [คติไทย]"** (เสียงพากย์คงไว้ได้)
- **#34 gate** — "แต่เจ้าชายไม่หันกลับ" → **"แต่เจ้าชายไม่ยอมกลับ"** (เพราะ NK เล่าว่าทรงหันไปมองเมือง)
- **#35 where2** — บนจอ "ระยะห่าง ~20 กม." → **"ระยะห่าง ~16 กม."**
- **#38 channa** — "สิ้นใจระหว่างทาง" → **"อรรถกถาเล่าว่า ม้ากัณฐกะเสียใจจนหัวใจแตก พอลับสายตาก็สิ้นใจ"**
- **#40 walk** — ทิศและคำว่า "ที่สุด" → **"นักบวชสิทธัตถะเดินเท้าลงไปทางตะวันออกเฉียงใต้ สู่แคว้นมคธ หนึ่งในแคว้นที่ใหญ่และรุ่งเรืองที่สุดในยุคนั้น เส้นตรงจากกบิลพัสดุ์ถึงราชคฤห์ กว่า 350 กิโลเมตร"**
- **#47 uruvela** — ระยะจริง 55 กม. (ไม่บังคับแก้) → **"ท่านเดินต่อไปทางตะวันตกเฉียงใต้ราว 55 กิโลเมตร ..."** · ป้ายบนจอ "แม่น้ำเนรัญชรา (ฟัลกุ)" → **"แม่น้ำเนรัญชรา (ลิลาจัน)"**
- **#49 austerity** — "จนเหลือวันละน้ำถั่วเพียงกอบมือเดียว" → **"จนกินน้ำถั่วทีละกอบมือ ทีละน้อย"** (ไม่บังคับแก้)
- **#50 body** — ผู้ที่พูดว่าสิ้นชีวิตคือเทวดา และภาพเปรียบคือลูกปัด → **"พระไตรปิฎกบรรยายว่า ข้อกระดูกสันหลังนูนเหมือนลูกปัดร้อยเป็นพวง ลูบหนังท้องก็ถึงกระดูกสันหลัง จนเทวดาบางองค์คิดว่าท่านสิ้นชีวิตไปแล้ว"**
- **#56 sujata** — (ไม่บังคับแก้) "ลูกสาวเศรษฐีในหมู่บ้าน" → **"ลูกสาวคหบดีในหมู่บ้านเสนานิคม"**
- **#58 grass** — เพิ่มป้ายการ์ดล่าง → **"หญ้าคา 8 กำมือ / ใต้ต้นโพธิ์ [อรรถกถา]"**
- **#59 vow** — ไม่ต้องแก้ แต่ใส่คำอธิบายคลิปว่าถ้อยคำนี้มีต้นแบบในพระไตรปิฎก (อุปัญญาตสูตร AN 2.5) ส่วนฉากใต้ต้นโพธิ์มาจากอรรถกถา
- **#60 mara** — NK บอกว่าชนะมารก่อนตะวันตก → **"เย็นวันนั้น ตามคัมภีร์ มารยกทัพมาขับไล่ ..."**
- **#61 witness** — "ท่านไม่พูดอะไร" ขัดกับ NK → **"มารท้าว่า ใครจะเป็นพยานว่าท่านบำเพ็ญบารมีมา ท่านยื่นพระหัตถ์ขวาลงแตะพื้นดิน ขอให้แผ่นดินเป็นพยาน นี่คือที่มาของพระพุทธรูปปางมารวิชัย"** · การ์ดล่าง **"แผ่นดินเป็นพยาน / ที่มาของปางมารวิชัย [อรรถกถา]"**
- **#62 thorani** — "แทบทุกวัด" ไม่มีตัวเลขรองรับ → **"ภาพนี้พบบนผนังโบสถ์ไทยหลายแห่ง"**
- **#54 lute** (คำอธิบายคลิป ไม่ต้องแก้เสียงพากย์) — เพิ่มว่า "ในพระไตรปิฎกมีอุปมาพิณคล้ายกัน คือที่พระพุทธเจ้าตรัสสอนพระโสณะ (AN 6.55) หลังตรัสรู้"
- **#14 maya7** (เพิ่มได้) — การ์ดล่าง **"7 วันหลังประสูติ / พระมารดาสวรรคต [ไตรปิฎก]"** (มีใน MN123)
- **#2 setup** (เลือกได้) — คงไว้ "ราว 2,600 ปีก่อน" ได้ เพราะตรงกับคติไทย ถ้าอยากให้ตรงกับทุกสำนัก ใช้ **"เมื่อกว่า 2,500 ปีก่อน"**
