# สามก๊กบนแผนที่ · ฉบับยาว 1: แปดปีที่ฮั่นพัง (ค.ศ. 184–192)

คลิปยาว YouTube แนวนอน 16:9 ~5 นาที · เล่าใหม่ทั้งหมดเป็นไทม์ไลน์ ไม่ได้ต่อคลิปสั้น · ภาพเปลี่ยนทุก 3–4 วินาที ป้ายปีวิ่งตามไทม์ไลน์ แผนที่กระดานคะแนนตอนต้นและตอนจบ
เสียง: ผู้เล่า (Charon) + เสียงตัวละคร 5 ประโยค · 45 ประโยค · 3701 ตัวอักษร ≈ 5:00

## เปิด · 8 ปีที่ฮั่นพัง

| ใคร | ประโยค |
|---|---|
| ผู้เล่า | 8 ปี ราชวงศ์ที่ครองแผ่นดินมา 400 ปี พังลงทั้งราชวงศ์ |
| ผู้เล่า | ด้วยชาวนาโพกผ้าเหลือง ขันทีสิบคน และขุนศึกอ้วนจากชายแดนคนเดียว นี่คือ 8 ปีแรกของสามก๊ก บนแผนที่ |

## ค.ศ. 184 · ฟ้าเหลืองจะขึ้นแทน

| ใคร | ประโยค |
|---|---|
| ผู้เล่า | ค.ศ. 184 ในวัง ขันทีกุมอำนาจ นอกวัง ชาวนาอดตาย |
| ผู้เล่า | หมอยาชื่อเตียวก๊ก มีลูกศิษย์หลายแสนคน แล้วเขาก็ประกาศ |
| **เตียวก๊ก** | ฟ้าสีครามสิ้นแล้ว ฟ้าสีเหลืองจะขึ้นแทน |
| ผู้เล่า | ไม่ถึงเดือน ชาวนาโพกผ้าเหลืองลุกฮือพร้อมกันใน 8 มณฑล เผาที่ว่าการเมืองไปทั่ว |

## สามพี่น้อง

| ใคร | ประโยค |
|---|---|
| ผู้เล่า | ที่เมืองโต๊ะกุ๋น คนสานเสื่อขายรองเท้าชื่อเล่าปี่ ได้พบคนขายเนื้อชื่อเตียวหุย และชายหน้าแดงชื่อกวนอู |
| ผู้เล่า | บันทึกบอกว่าเล่าปี่แขนยาวเลยเข่า เหลือบตาก็มองเห็นใบหูตัวเอง พูดน้อย แต่ใครพบก็รัก |
| ผู้เล่า | นิยายบอกว่าทั้งสามสาบานในสวนท้อ แต่บันทึกจริงบอกแค่ว่า พวกเขานอนเตียงเดียวกัน รักกันเหมือนพี่น้อง |
| ผู้เล่า | เล่าปี่ได้งานแรกเป็นนายทหารอำเภอเล็ก ๆ แล้วถูกขุนนางตรวจราชการไล่ ในบันทึกจริง เขาจับขุนนางคนนั้นมัด แล้วเฆี่ยนเอง 200 ที |

## กบฏแตก ขุนศึกผงาด

| ใคร | ประโยค |
|---|---|
| ผู้เล่า | ส่วนเตียวก๊กไม่ได้ตายในสนามรบ เขาป่วยตายก่อนเมืองแตก ภายในปีเดียว กบฏผ้าเหลืองก็แตกพ่าย |
| ผู้เล่า | แต่ราชสำนักต้องยอมให้เจ้าเมืองตั้งทัพเอง แผ่นดินเริ่มแตกเป็นก๊ก ๆ |
| ผู้เล่า | หนึ่งในนายทหารที่ได้ชื่อจากศึกนี้ คือชายร่างเล็กชื่อโจโฉ ที่นักดูคนเคยทำนายไว้ว่า |
| **ผู้ทำนาย** | ยามบ้านเมืองวุ่นวาย ท่านจะเป็นวีรบุรุษกังฉิน |
| ผู้เล่า | คนทั่วไปคงโกรธ แต่โจโฉกลับหัวเราะชอบใจ |

## ค.ศ. 189 · วังนองเลือด

| ใคร | ประโยค |
|---|---|
| ผู้เล่า | ค.ศ. 189 ฮ่องเต้สวรรคต แม่ทัพโฮจิ๋นอยากล้างบางขันที จึงเรียกขุนศึกจากหัวเมืองเข้าเมืองหลวง |
| ผู้เล่า | แต่ขันทีลงมือก่อน โฮจิ๋นถูกตัดหัวกลางวัง อ้วนเสี้ยวบุกเข้าไปแก้แค้น ฆ่าทุกคนที่ไม่มีหนวด ขันทีตายกว่า 2,000 คน |
| ผู้เล่า | ฮ่องเต้วัย 14 กับน้องชาย หนีออกจากวังกลางดึก จนเจอทัพหนึ่งที่ริมแม่น้ำหวงโห ทัพของตั๋งโต๊ะ ขุนศึกที่โฮจิ๋นเรียกมาเอง |
| ผู้เล่า | ฮ่องเต้วัย 14 ร้องไห้จนพูดไม่เป็นคำ แต่น้องชายวัย 8 ขวบกลับตอบตั๋งโต๊ะได้ฉะฉาน ตั๋งโต๊ะยิ้ม เขาเพิ่งเจอฮ่องเต้องค์ใหม่ที่ต้องการ |

| ผู้เล่า | แล้วเขาก็ยุลิโป้ ขุนพลที่เก่งที่สุดในแผ่นดิน ให้ตัดหัวเต๊งหงวน ผู้มีพระคุณของตัวเอง |
| ผู้เล่า | นิยายบอกว่าราคาของการทรยศครั้งนี้ คือม้าเซ็กเธาว์ ม้าที่วิ่งได้วันละพันลี้ |
| ผู้เล่า | ตั๋งโต๊ะปลดฮ่องเต้ ตั้งน้องชายวัย 8 ขวบขึ้นแทน แล้วพกดาบใส่รองเท้าเดินเข้าท้องพระโรง |

## ค.ศ. 190 · เหล้ายังอุ่น

| ใคร | ประโยค |
|---|---|
| ผู้เล่า | ค.ศ. 190 ขุนศึกทั่วแผ่นดินรวมทัพปราบตั๋งโต๊ะ อ้วนเสี้ยวเป็นแม่ทัพใหญ่ ทหารกว่าแสนคน แต่จัดเลี้ยงสุรากันทุกวัน |
| ผู้เล่า | โจโฉทนไม่ไหว ยกทัพของตัวเองบุกไปลำพัง แล้วแพ้ยับ เกือบเอาชีวิตไม่รอด |
| ผู้เล่า | นิยายบอกว่ากวนอูตัดหัวฮัวหยงกลับมา ขณะเหล้าในจอกยังอุ่น แต่บันทึกจริง คนทำคือทัพของซุนเกี๋ยน ขุนพลจากแดนใต้ |
| ผู้เล่า | ซุนเกี๋ยนเป็นคนเดียวที่ตีทัพตั๋งโต๊ะแตกจริง จนบุกใกล้ถึงเมืองหลวง |

## ค.ศ. 191 · ลูกธนูดอกเดียว

| ใคร | ประโยค |
|---|---|

## ค.ศ. 192 · หญิงงามคนเดียว

| ใคร | ประโยค |
|---|---|
| ผู้เล่า | ค.ศ. 192 ที่เตียงอัน ขุนนางอ้องอุ้นวางแผนฆ่าตั๋งโต๊ะ |
| ผู้เล่า | นิยายบอกว่าเขาใช้หญิงงามชื่อเตียวเสี้ยน ยุให้ลิโป้กับตั๋งโต๊ะแย่งนาง แต่บันทึกจริงไม่มีเตียวเสี้ยน มีแค่หอกที่ตั๋งโต๊ะขว้างใส่ลิโป้ กับสาวใช้ที่ลิโป้แอบคบ |
| ผู้เล่า | แล้วตั๋งโต๊ะก็ถูกลิโป้แทงตายหน้าประตูวัง ทหารจุดไส้ตะเกียงไว้ที่สะดือศพ ไฟลุกอยู่หลายวัน |
| ผู้เล่า | ลิโป้กลายเป็นวีรบุรุษ แต่ไม่ถึงสองเดือน ลูกน้องตั๋งโต๊ะก็ยกทัพกลับมาล้างแค้น จนลิโป้ต้องหนีออกจากเตียงอัน |
