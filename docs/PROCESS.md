# กระบวนการทำ

บันทึกวิธีทำ skill นี้ และวิธีทำคลิปตอนตัวอย่าง "ศึกผาแดง" ตั้งแต่ต้นจนจบ รวมถึงปัญหาที่เจอและวิธีแก้

## 1. แนวคิด

- ทุกภาพเป็นโค้ด: Remotion (React → วิดีโอ) + d3-geo (ฉายพิกัดโลกลงจอ) + ข้อมูลแผนที่เปิด
- ฉากเป็นฟังก์ชันของเลขเฟรมล้วน ๆ (`useCurrentFrame()`) ทำให้เรนเดอร์ซ้ำได้ผลเหมือนเดิมทุกครั้ง
- โค้ดชุดเดียวใช้ได้ทั้ง 16:9 และ 9:16 เพราะทุกขนาดคิดจากหน่วย `s = min(width, height) / 1080`
- หยุดรออนุมัติ 3 จุด: บท → ภาพนิ่งตัวอย่าง → คลิปสุดท้าย และไม่อัปโหลดขึ้นช่องเอง

## 2. ตั้งเครื่อง

| เครื่องมือ | ใช้ทำอะไร |
|---|---|
| Node.js ≥ 18 (หรือ Bun) | รัน Remotion และสคริปต์ |
| ffmpeg / ffprobe | แปลงไฟล์เสียง วัดความยาว ตรวจความดัง |
| Remotion 4 | เรนเดอร์วิดีโอด้วย Chrome headless |
| d3-geo, topojson-client, world-atlas | ฉายแผนที่ และข้อมูลประเทศ/แผ่นดิน Natural Earth |
| Gemini API key | พากย์เสียง (TTS) และตรวจคำพากย์ (ถอดเสียง) |

## 3. คอมโพเนนต์หลัก (`skills/map-studio/template/src/components`)

| ไฟล์ | หน้าที่ |
|---|---|
| `camera.ts` | กล้อง `{lon, lat, scale}` เลื่อนตามเส้นวงกลมใหญ่ ซูมแบบ log scale ทำให้ความเร็วซูมดูคงที่ และ `camForFeature` จัดเฟรมให้พอดีพื้นที่ |
| `Map.tsx` | `<MapFrame>` ส่ง projection ให้ทุกเลเยอร์ / ลูกโลก / เส้นกริด / ประเทศ / ระบายสี |
| `Labels.tsx` | ป้ายเมือง (จุด + วงกระเพื่อม) และป้ายพื้นที่ที่จางหายเองเมื่อพื้นที่เล็กลงบนจอ |
| `Route.tsx` | เส้นทางบินแบบวาดสด + เครื่องบิน + ตัวนับ กม. + นาฬิกา |
| `Arrow.tsx` | ลูกศรเคลื่อนทัพแบบเรียว (ทึบ) และแบบเส้นประ (ถอยทัพ / ทูต) |
| `Region.tsx` | เขตอิทธิพลโดยประมาณ วาดจากพิกัดที่กำหนดเอง ตัดให้อยู่บนแผ่นดิน |
| `Caption.tsx` | คำบรรยายใต้ภาพ แบ่งตามวรรคของบท ขึ้นตรงคำพูดเมื่อมีจังหวะรายคำจาก `npm run align` |
| `subs.mjs` | จัดเวลาแต่ละช่วงบท (`buildBeats`) และเวลาคำบรรยาย ใช้ร่วมกันทั้งฉากและสคริปต์ srt / คำอธิบายคลิป |
| `Overlays.tsx` | ปฏิทินฉีก / ชื่อเรื่อง / เครดิต / ตัวเลขนับขึ้น |
| `Reasons.tsx` | ป้ายเหตุผล 1 2 3 เด้งขึ้นตามจังหวะพากย์ ข้อล่าสุดเด่น ข้อก่อนหน้าจางลง |
| `Sound.tsx` | เพลงประกอบที่ลดเสียงเองตอนมีเสียงพากย์ และเสียงเอฟเฟกต์ (`Sfx`) |
| `Thumbnail.tsx` | ภาพปก = เฟรมจากคลิป + หัวข้อตัวใหญ่ เน้นคำสำคัญด้วยสี |

สคริปต์ใน `template/scripts`: `align` (จังหวะรายคำด้วย Whisper), `srt` (ไฟล์คำบรรยาย), `describe`
(คำอธิบายคลิป + บทพร้อมเวลา + เครดิต), `thumb` (ภาพปก), `sfx` (สร้างเสียงเอฟเฟกต์ด้วยคณิตศาสตร์
ไม่ต้องมีสิทธิ์ใช้งาน), `loudness` (ปรับความดังเป็น −14 LUFS)

## 4. ขั้นตอนทำ 1 ตอน (ตัวอย่าง ศึกผาแดง)

1. **บท** เขียนเป็นช่วง (beat) ลงใน `beats.json` ช่องละประโยค ช่อง `text` คือสิ่งที่ให้ TTS อ่าน
   (เขียนตัวเลขเป็นคำ เช่น "สองร้อยแปด") ส่วนช่อง `caption` คือข้อความที่ขึ้นจอ (ใช้ตัวเลขได้)
2. **ตรวจข้อเท็จจริง** แยกตัวเลขในนิยายออกจากบันทึกประวัติศาสตร์ เช่น โจโฉ "ประกาศ" ว่ามีทัพแปดแสน
   ส่วนที่ประเมินจริงราวสองแสน และระบุบนจอว่าตำแหน่งผาแดงเป็นตำแหน่งโดยประมาณ
3. **พากย์** `GEMINI_API_KEY=... npm run tts -- redcliffs` ได้ไฟล์เสียงแยกตามช่วง + `timing.json`
4. **ตรวจเสียง** `npm run transcribe -- public/audio/redcliffs/01.wav` แล้วเทียบกับบท โดยเฉพาะชื่อเฉพาะ
   (โจโฉ, เล่าปี่, ขงเบ้ง, ซุนกวน, กังตั๋ง, เซ็กเพ็ก, อุยกาย, ฮัวหยง)
5. **ข้อมูลแผนที่** ดึงแม่น้ำและทะเลสาบ Natural Earth 1:10m เฉพาะกรอบประเทศจีน แล้วย่อพิกัดเหลือทศนิยม
   3 ตำแหน่ง ได้ไฟล์ 330 KB (`china-water.json`) ตัดอ่างเก็บน้ำสมัยใหม่ (Shuiku) ออก เพราะยังไม่มีในยุคนั้น
6. **ฉาก** กำหนดเวลาจาก `timing.json` ทุกอย่างอ้างอิงจุดเริ่มของแต่ละช่วง เช่น `B.fire.start + 15`
   เปลี่ยนบทแล้วภาพจะตามเสียงเอง
7. **ภาพนิ่ง** `npx remotion still RedCliffs out/x.png --frame=N --scale=0.5` ทุกช่วง รวมเป็นแผ่นเดียว
   ด้วย ffmpeg `hstack/vstack` แล้วตรวจก่อนเรนเดอร์จริง
8. **เรนเดอร์** `npx remotion render RedCliffs` (16:9) และ `RedCliffsVertical` (9:16)

## 5. ปัญหาที่เจอ และวิธีแก้

| ปัญหา | สาเหตุ | วิธีแก้ |
|---|---|---|
| ลูกโลกตอนเปิดเรื่องเป็นวงสีเขียวทึบ ไม่เห็นแผ่นดิน | ทะเลสาบเล็กหนึ่งแห่งถูกปัดพิกัดจนรูปเพี้ยน d3 เลยตีความว่า "ทั้งโลกยกเว้นทะเลสาบนี้" | ตัด polygon ที่ `geoArea > 2π` ทิ้ง |
| เขตที่วาดเองระบายทั้งโลก | วงพิกัดวนทวนเข็ม (d3 ต้องการตามเข็ม) | `region()` เช็กพื้นที่แล้วกลับลำดับจุดให้อัตโนมัติ |
| กองเรืออยู่บนบก ไม่อยู่ในแม่น้ำ | ระยะห่างจากเส้นแม่น้ำที่ตั้งไว้กว้างเกินเมื่อซูมเข้ามาก | วางเรือห่างจากเส้นกลางแม่น้ำไม่เกิน ~0.01° และขยายความกว้างแม่น้ำตามระดับซูม |
| ป้ายชื่อซ้อนกันตอนซูมออก | ป้ายประเทศขนาดคงที่ขณะที่ประเทศเล็กลงบนจอ | ป้ายพื้นที่จางหายเมื่อกว้างไม่ถึง `minWidth` |
| Cloud Text-to-Speech ปฏิเสธ key | API นี้ไม่รับ API key | ใช้ Gemini TTS (`gemini-3.8-flash-tts`, เสียง Charon) แทน |
| TTS อ่านคำสั่งภาษาอังกฤษออกมาด้วย หรือพูดเพี้ยน | ใส่คำสั่งสไตล์ไว้ในข้อความ | ส่งเฉพาะข้อความภาษาไทยล้วน |
| npm / Remotion พังบน Windows | path ยาวเกินขีดจำกัดของ Windows | ทำงานใน path สั้น เช่น `C:\tmp\ms` |
| เรนเดอร์ช้า (1 นาทีใช้เวลานาน) | ฟิลเตอร์ลายกระดาษ (feTurbulence) เต็มจอถูกคำนวณใหม่ทุกเฟรม | เรนเดอร์ลายกระดาษเป็น PNG ครั้งเดียวต่อขนาดจอ (`PaperTex16` / `PaperTex9`) แล้ววางทับด้วย `<Img>` |

| ภาพปกเป็นเฟรมแรกเสมอ ไม่ใช่เฟรมที่เลือก | `<Freeze>` เลื่อนได้ไม่เกินความยาวของ composition (ปกยาว 1 เฟรม) | ตั้ง `durationInFrames` ของ composition ภาพปกให้เท่าความยาวตอน |
| เสียง whoosh ที่สร้างเองแทบไม่มีเสียง | `bandpass` ของ ffmpeg อ่าน `w` เป็นค่า Q โดยปริยาย ช่วงความถี่เลยแคบมาก | ใส่ `width_type=h` ให้ `w` เป็นเฮิรตซ์ |
| เรนเดอร์ช้า ~11.5 นาทีต่อไฟล์ 75 วินาที | Chrome แบบไม่มีหน้าจอวาดภาพด้วยซอฟต์แวร์ | `Config.setChromiumOpenGlRenderer("vulkan")` เร็วขึ้น 3.8 เท่า ภาพเหมือนเดิม (วัดบน RTX 2060) |
| Whisper ช้า 3–4 นาทีต่อตอน | รุ่นที่ Remotion ติดตั้งบน Windows ใช้ CPU และโหลดโมเดล 3 GB ใหม่ทุกช่วง | ใช้ whisper.cpp รุ่น CUDA และส่งทุกช่วงในคำสั่งเดียว (~27 วินาทีต่อตอน) ต้องใส่ `-nfa` ไม่งั้น DTW ถูกปิด |
| Gemini ตอบ 429 กลางทาง | free tier จำกัดจำนวนครั้งต่อนาที | `tts-gemini.mjs` รอตาม `retryDelay` แล้วลองใหม่เอง |
| ส่งตัวฉากผ่าน props ของภาพปกไม่ได้ (React error #130) | Remotion ส่ง props เป็น JSON ฟังก์ชันจึงหาย | สร้างตัวห่อภาพปกของแต่ละตอนไว้ใน `compositions.tsx` |

## 6. สิ่งที่ยังไม่ได้ทำ

- ตอนผาแดงยังไม่ได้รัน `npm run align` (ไฟล์เสียงไม่ได้เก็บใน repo) คำบรรยายจึงยังแบ่งเวลาตามจำนวนตัวอักษร
  จนกว่าจะสร้างเสียงใหม่แล้วรัน align
- ทดสอบ align ด้วยเสียงพากย์ภาษาอังกฤษและโมเดล `base` แล้ว ยังไม่ได้ทดสอบกับเสียงไทยจริงและโมเดล `large-v3`
- ยังไม่มีเพลงประกอบในตอนตัวอย่าง (ต้องใช้เพลงที่มีสิทธิ์ใช้เชิงพาณิชย์) คอมโพเนนต์ `Music` พร้อมใช้แล้ว
- เขตอิทธิพลของแต่ละก๊กวาดคร่าว ๆ ด้วยมือ ควรเทียบกับแผนที่ประวัติศาสตร์อ้างอิงอีกครั้งก่อนลงช่องจริง
