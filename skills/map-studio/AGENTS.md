# Map Studio (for Codex, Cursor and other agents)

This folder is an agent skill for making map-storytelling videos drawn entirely with code
(Remotion + d3-geo + open map data). Read `SKILL.md` first and follow it exactly — it lists the hard rules,
the approval gates and which file under `references/` to read for each step. The Remotion starter project is
in `template/`.
