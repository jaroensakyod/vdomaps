# คำสั่งสำหรับสไตล์ M12 ข่าวต่างประเทศรายวัน

ก๊อปทีละข้อไปวางในผู้ช่วย AI (Claude Code / Codex) แล้วเปลี่ยนข้อความใน [ ]

**1. เรื่องและบท**
```
ใช้สไตล์ M12 ข่าวต่างประเทศรายวัน ทำคลิปข่าวโลกประจำวันที่ [วันนี้] [6 เรื่อง] ยาว [60 วินาที] แนวตั้ง
หาข่าวใน 24 ชั่วโมงที่ยืนยันได้ 2 แหล่ง เปิดด้วยประโยคช็อกของข่าวแรก เขียนบทเป็นตารางให้ดูก่อน
```

**2. ภาพนิ่ง**
```
บทผ่านแล้ว ทำภาพนิ่งตามสไตล์ M12 ให้ดู 3 ภาพ: เฟรมแรก (ประโยคช็อก), การ์ดเปิด, และข่าวเรื่องแรก
```

**3. เสียงและคลิปทดสอบ**
```
ภาพผ่าน ทำเสียงพากย์ ซับตามคำ ภาพประกอบเปลี่ยนทุก 3–4 วินาทีตามคำพากย์ ใส่เสียงบรรยากาศให้เบา แล้วเรนเดอร์ 10 วินาทีแรกให้ดู
```

**4. ตัวเต็ม**
```
เรนเดอร์ตัวเต็ม พร้อมปก ข้อความโพสต์สรุปทีละข้อ ลิงก์ที่มา เครดิตแผนที่ และบอกว่าเสียงสร้างด้วย AI
```

## ตัวอย่างเรื่องที่เหมาะ

1. ข่าวโลกวันนี้ 8 เรื่องใน 90 วินาที
2. สรุปพายุและน้ำท่วมทั่วโลกสัปดาห์นี้
3. ข่าวการเมืองโลกประจำวัน — เลือกตั้ง สภา ผู้นำคนใหม่
