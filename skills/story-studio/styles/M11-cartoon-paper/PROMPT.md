# คำสั่งสำหรับสไตล์ M11 แผนที่การ์ตูนกระดาษ

ก๊อปทีละข้อไปวางในผู้ช่วย AI (Claude Code / Codex) แล้วเปลี่ยนข้อความใน [ ]

**1. เรื่องและบท**
```
ใช้สไตล์ M11 ทำคลิปเรื่อง [ศึกบางระจัน] สำหรับเด็ก ยาว [60 วินาที] แนวตั้ง — หาข้อมูล เขียนบทภาษาง่าย ๆ ให้ดูก่อน
บอกด้วยว่าแต่ละฉากใช้ไอคอนการ์ตูนตัวไหน และมีควิซหนึ่งข้อ
```

**2. ภาพนิ่ง**
```
บทผ่านแล้ว ดึงข้อมูลแม่น้ำตามหัวข้อ Data ใน STYLE.md ของ M11 แล้วทำภาพนิ่ง 3 ฉากตามสไตล์ให้ดู
(แผนที่ภาพรวมพร้อมลูกศรทัพ, ซูมเข้าเมือง, การ์ดควิซ)
```

**3. เสียงและคลิปทดสอบ**
```
ภาพผ่าน ทำเสียงพากย์น้ำเสียงสดใส ซับ ใส่เสียงกลอง ช้าง ฝน จากคลังเสียงแบบเบา ๆ แล้วเรนเดอร์ 10 วินาทีแรกให้ดู
```

**4. ตัวเต็ม**
```
เรนเดอร์ตัวเต็ม พร้อมปก คำอธิบายคลิป และเครดิตแผนที่
```

## ตัวอย่างเรื่องที่เหมาะ

1. ศึกบางระจัน — ชาวบ้านสู้ทัพพม่า เล่าให้เด็กฟัง
2. ทำไมอยุธยาถึงเป็นเกาะ — น้ำหลากหน้าฝนช่วยป้องกันเมือง
3. พระเจ้าตากตีฝ่าวงล้อม — เส้นทางไปจันทบุรี
