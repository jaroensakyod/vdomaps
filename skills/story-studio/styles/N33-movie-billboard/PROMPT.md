# คำสั่งสำหรับสไตล์ N33 ป้ายหนังเขียนมือ

ก๊อปทีละข้อไปวางในผู้ช่วย AI (Claude Code / Codex) แล้วเปลี่ยนข้อความใน [ ]

**1. เรื่องและบท**
```
ใช้สไตล์ N33 ป้ายหนังเขียนมือ ทำคลิปเรื่อง [โรงหนังเก่าประจำอำเภอ] ยาว [45 วินาที] แนวตั้ง — หาข้อมูล เขียนบทให้ดูก่อน
บอกด้วยว่าแต่ละฉากจะวาดป้ายอะไร หน้าตัวละครแบบไหน และชื่อเรื่องบนป้ายว่าอะไร
```

**2. ภาพนิ่ง**
```
บทผ่านแล้ว ทำภาพนิ่ง 3 ฉากตามสไตล์ N33 ให้ดู — ป้ายเต็มบนนั่งร้านตอนกลางคืน 1 ภาพ
และภาพใกล้หน้าตัวละครที่ลงสีด้วยแปรง 1 ภาพ ใช้ตัวละครที่ออกแบบใหม่ ไม่ใช่ดาราจริง
```

**3. เสียงและคลิปทดสอบ**
```
ภาพผ่าน ทำเสียงพากย์ ซับ ใส่เสียงแปรง เสียงไฟป้ายติด และเสียงถนนตอนค่ำจากคลังเสียง แล้วเรนเดอร์ 10 วินาทีแรกให้ดู
```

**4. ตัวเต็ม**
```
เรนเดอร์ตัวเต็ม พร้อมปก คำอธิบายคลิป และเครดิต
```

**ใช้เป็นฉากพิเศษในคลิปยาว**
```
ในตอนนี้ ขอฉาก [ป้ายหนังเรื่องดังของยุคนั้น] แบบ N33 ยาว 8 วินาที แทรกกลางช่วง [ch2]
วาดตัวละครใหม่ ติดป้าย "ภาพประกอบ"
```

## ตัวอย่างเรื่องที่เหมาะ

1. ชีวิตช่างเขียนป้ายหนัง — จากตารางดินสอถึงป้ายสูงสามชั้น
2. ยุคทองหนังกลางแปลงและโรงหนังสแตนด์อโลน
3. เล่าประวัติบุคคลดังแบบ "ป้ายหนังชีวิต" (ใช้รูปของช่องเองผ่านช่อง `photo` หรือวาดตัวละครใหม่)
