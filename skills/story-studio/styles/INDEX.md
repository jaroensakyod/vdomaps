# 48 styles

Pick by story, then open `<ID>-<slug>/STYLE.md`. Every finished pack has code (`Demo.tsx` + `kit/`); install it
with `npm run style -- <ID>`. Formats: V = 9:16, W = 16:9. A folder that does not exist yet is a
style still being made — tell the user it is not available yet.
**Set:** `199` = in both editions · `399` = full edition only (the 199 edition ships 24 styles).
