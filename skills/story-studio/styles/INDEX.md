# 72 styles

Pick by story, then open `<ID>-<slug>/STYLE.md`. Every finished pack has code (`Demo.tsx` + `kit/`); install it
with `npm run style -- <ID>`. Formats: V = 9:16, W = 16:9. All 72 packs are finished.
**Set:** `basic` = Basic 199 and up · `pro` = Pro 299 and up · `premium` = Premium 990 only (Basic ships 24 styles, Pro 48, Premium 72).
