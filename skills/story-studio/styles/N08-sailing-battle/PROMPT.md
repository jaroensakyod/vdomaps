# คำสั่งสำหรับสไตล์ N08 เรือใบรบกลางทะเล (ภาพพิมพ์แกะไม้)

ก๊อปทีละข้อไปวางในผู้ช่วย AI (Claude Code / Codex) แล้วเปลี่ยนข้อความใน [ ]

**1. เรื่องและบท**
```
ใช้สไตล์ N08 เรือใบรบกลางทะเล (ภาพพิมพ์แกะไม้) ทำคลิปเรื่อง [ยุทธนาวีทราฟัลการ์ 1805] ยาว [60 วินาที] แนวตั้ง —
หาข้อมูล เขียนบทให้ดูก่อน บอกด้วยว่าแต่ละช่วงเรือฝ่ายไหนยิง ถูกตรงไหน และกล้องเลื่อนไปทางไหน
พร้อมข้อความในกรอบชื่อเรื่อง (มุมซ้ายบน) ของแต่ละช่วง
```

**2. ภาพนิ่ง**
```
บทผ่านแล้ว ทำภาพนิ่ง 3 ฉากตามสไตล์ N08 ให้ดู — สองลำเข้าประชิด ยิงกราบเรือมีควันดินปืน และเสากระโดงหักไฟลุก
เส้นดำแบบแม่พิมพ์ไม้ ท้องฟ้าไล่สีน้ำเงินลงมาเป็นกระดาษ คลื่นม้วนมีฟองเป็นกรงเล็บ สีธงสองฝ่ายต้องต่างกันชัด
```

**3. เสียงและคลิปทดสอบ**
```
ภาพผ่าน ทำเสียงพากย์ ซับ ใส่เสียงคลื่น ลม ไม้เรือลั่น ปืนใหญ่ทีละกระบอก น้ำกระจาย จากคลังเสียง
ให้ตรงเฟรมที่ภาพเกิด แล้วเรนเดอร์ 10 วินาทีแรกให้ดู
```

**4. ตัวเต็ม**
```
เรนเดอร์ตัวเต็ม พร้อมปก คำอธิบายคลิป และเครดิต
```
