# คำสั่งสำหรับสไตล์ N14 สมุดข่อย

ก๊อปทีละข้อไปวางในผู้ช่วย AI (Claude Code / Codex) แล้วเปลี่ยนข้อความใน [ ]

**1. เรื่องและบท**
```
ใช้สไตล์ N14 สมุดข่อย ทำคลิปเล่าตำนาน [พระมาลัยโปรดสัตว์นรก] ยาว [60 วินาที] แนวตั้ง — หาข้อมูล เขียนบทให้ดูก่อน
แบ่งเป็นหน้าสมุดข่อย หน้าละ 1 ฉาก บอกด้วยว่าแต่ละหน้ามีภาพวาดอะไรและข้อความ 4 บรรทัดว่าอะไร
```

**2. ภาพนิ่ง**
```
บทผ่านแล้ว ทำภาพนิ่ง 3 หน้าตามสไตล์ N14 ให้ดู สมุดข่อยขาวพับไปมา ภาพวาดสีฝุ่นตัดเส้นดำ ตัวหนังสือเขียนด้วยหมึก
อย่าลอกภาพจากสมุดข่อยจริง วาดใหม่ทั้งหมด
```

**3. เสียงและคลิปทดสอบ**
```
ภาพผ่าน ทำเสียงพากย์ ซับ ใส่เสียงฆ้องหรือระฆังเบา ๆ จากคลังเสียง ให้หน้ากระดาษคลี่ตรงกับคำพากย์
แล้วเรนเดอร์ 10 วินาทีแรกให้ดู
```

**4. ตัวเต็ม**
```
เรนเดอร์ตัวเต็ม พร้อมปก คำอธิบายคลิป และแหล่งที่มาของตำนาน
```

1. พระมาลัยกับดอกบัวแปดดอก — ขึ้นสวรรค์ไปบูชาพระจุฬามณี

3. ไตรภูมิ — โลกสามแบบในความเชื่อโบราณ
