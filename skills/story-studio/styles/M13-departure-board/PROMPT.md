**1. เรื่องและบท**
```
ใช้สไตล์ M13 กระดานขบวนทัพ ทำคลิปเรื่อง [สงครามเก้าทัพ] ยาว [60 วินาที] แนวตั้ง — แบ่งกองทัพเป็นสาย ๆ
(ไม่เกิน 4 สาย) หาวันที่แต่ละสายถึงเมืองสำคัญ นับวันแรกเป็นวันที่ 1 เขียนบทให้ดูก่อน พร้อมตาราง
[สาย, เมือง, ลองจิจูด, ละติจูด, วันที่ถึง] และแหล่งที่มา
```

**2. ภาพนิ่ง**
```
บทผ่านแล้ว ทำภาพนิ่ง 3 ภาพตามสไตล์ M13 ให้ดู: ตอนเริ่ม (ป้ายกำลังพลิก) ตอนกลางเรื่อง และตอนจบ
เป็นป้ายตัวเลขพลิกแบบสถานีรถไฟ กรอบอะลูมิเนียม ป้ายเคลือบสีเขียวด้านบน แผนที่ไฟ LED สีอำพันแบบจุด
แต่ละทัพเป็นแถว "สาย" มีปลายทาง วันที่ และสถานะบนแผ่นพลิก เส้นทางบนแผนที่สว่างขึ้นทีละจุด
```

**3. เสียงและคลิปทดสอบ**
```
ภาพผ่าน ทำเสียงพากย์ ซับตามคำ ให้ตัวนับวันและแผ่นพลิกเปลี่ยนตรงคำพากย์ ใส่เสียงแผ่นพลิกเบา ๆ
และเสียงเดินทัพจากคลังเสียง แล้วเรนเดอร์ 10 วินาทีแรกให้ดู
```

