# คำสั่งสำหรับสไตล์ N30 กระดาษหินอ่อน

ก๊อปทีละข้อไปวางในผู้ช่วย AI (Claude Code / Codex) แล้วเปลี่ยนข้อความใน [ ]

**1. เรื่องและบท**
```
ใช้สไตล์ N30 กระดาษหินอ่อน ทำคลิปเรื่อง [ตำนานพระแม่โพสพ] ยาว [45 วินาที] แนวตั้ง — เล่าใหม่ด้วยคำของเราเอง
เขียนบทให้ดูก่อน บอกด้วยว่าแต่ละฉากหยดสีอะไร หวีลายแบบไหน และดึงรูปอะไรด้วยเหล็กแหลม
```

**2. ภาพนิ่ง**
```
บทผ่านแล้ว ทำภาพนิ่ง 3 ฉากตามสไตล์ N30 ให้ดู พื้นเป็นหยดสีใหญ่ หยดเล็กโปรยทับ หวีเป็นคลื่น
ตัวละครทำจากหยดสีที่ดึงด้วยเหล็กแหลม ไม่มีเส้นร่าง
```

**3. เสียงและคลิปทดสอบ**
```
ภาพผ่าน ทำเสียงพากย์ ซับ ใส่เสียงฝนหรือลมเบา ๆ จากคลังเสียง แล้วเรนเดอร์ 10 วินาทีแรกให้ดู
```

**4. ตัวเต็ม**
```
เรนเดอร์ตัวเต็ม จบด้วยการวางกระดาษแล้วยกขึ้นเป็นภาพพิมพ์ พร้อมปก คำอธิบายคลิป และเครดิต
```

## ตัวอย่างเรื่องที่เหมาะ

1. ตำนานนางสงกรานต์ — ทำไมทุกปีมีนางสงกรานต์คนใหม่
2. ความฝันทำงานอย่างไร — ภาพในหัวที่ไหลและเปลี่ยนรูปตลอดเวลา
3. ตำนานพญานาคกับบั้งไฟพญานาค (บอกชัดว่าเป็นความเชื่อ)
