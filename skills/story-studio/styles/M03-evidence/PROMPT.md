# คำสั่งสำหรับสไตล์ M03 ใบลานหลักฐาน

ก๊อปทีละข้อไปวางในผู้ช่วย AI (Claude Code / Codex) แล้วเปลี่ยนข้อความใน [ ]

**1. เรื่องและบท**
```
ใช้สไตล์ M03 ใบลานหลักฐาน ทำคลิปเรื่อง [การเสียกรุงศรีอยุธยาครั้งที่ 2] ยาว [10 นาที] แนวตั้ง —
หาหลักฐานทุกฝ่าย ทำ sources.md บอกว่าฉบับไหนพูดว่าอะไร เขียนเมื่อไหร่ และระดับความน่าเชื่อถือ แล้วเขียนบทให้ดูก่อน
```

**2. ภาพนิ่ง**
```
บทผ่านแล้ว ดึงข้อมูลแผนที่ตาม STYLE.md แล้วทำภาพนิ่ง 3 ฉากตามสไตล์ M03 ให้ดู
ทุกอย่างเป็นใบลานบนโต๊ะไม้ แผนที่จารบนใบลานสี่ใบผูกเชือกแดง ใบหัวเรื่องมีปมเชือกบอกความน่าเชื่อถือ
และใบลานของแต่ละหลักฐานเลื่อนออกมาจากกองใต้แผนที่
```

**3. เสียงและคลิปทดสอบ**
```
ภาพผ่าน ทำเสียงพากย์ ซับ ให้ใบลานหลักฐานเลื่อนออกและคำจารขึ้นตรงคำพูด ตราครั่งประทับตรงจุดที่ตรงกัน/ถกเถียง ใส่เสียงบรรยากาศจากคลังเสียง แล้วเรนเดอร์ 10 วินาทีแรกให้ดู
```

**4. ตัวเต็ม**
```
เรนเดอร์ตัวเต็ม พร้อมปก คำอธิบายคลิป รายการหลักฐาน และเครดิตแผนที่
```

1. ยุทธหัตถี — ง้าว หอก หรือปืน และรบกันที่ไหน

3. กรุงศรีฯ แตกเพราะอะไร — ไส้ศึก ข้าวหมด หรือทัพพม่าแข็งกว่า
