**1. เรื่องและบท**
```

เขียนบทให้ดูก่อน บอกด้วยว่าข้อความบนม้วนกระดาษแต่ละช่วงพิมพ์ว่าอะไร (สั้น บรรทัดละไม่เกิน 24 ตัว)
```

**2. ภาพนิ่ง**
```
บทผ่านแล้ว ทำภาพนิ่ง 3 ช่วงตามสไตล์ N16 ให้ดู ตัวอักษรต้องเป็นจุดแบบเครื่องโทรพิมพ์ มีแถบเทปเจาะรูวิ่งด้านล่าง
แสงเย็นแบบออฟฟิศตอนกลางคืน ถ้าข้อความไม่ใช่ของจริงให้ติดป้าย "ตัวอย่าง"
```

```
ภาพผ่าน ทำเสียงพากย์ ซับ ใส่เสียงเคาะตัวอักษรเบา ๆ และเสียงกระดิ่งตอนขึ้นบรรทัดใหม่ (ใต้เสียงพากย์)
แล้วเรนเดอร์ 10 วินาทีแรกให้ดู

```
