# คำสั่งสำหรับสไตล์ N27 หุ่นละครเล็ก

ก๊อปทีละข้อไปวางในผู้ช่วย AI (Claude Code / Codex) แล้วเปลี่ยนข้อความใน [ ]

**1. เรื่องและบท**
```
ใช้สไตล์ N27 หุ่นละครเล็ก ทำคลิปเรื่อง [ขุนช้างขุนแผน ตอนกำเนิดพลายงาม] ยาว [60 วินาที] แนวตั้ง — หาข้อมูล
เขียนบทให้ดูก่อน บอกด้วยว่าแต่ละฉากใช้ฉากหลังผ้าวาดแบบไหน หุ่นตัวไหน ท่าอะไร
```

**2. ภาพนิ่ง**
```
บทผ่านแล้ว ทำภาพนิ่ง 3 ฉากตามสไตล์ N27 ให้ดู หุ่นต้องมีไม้เชิด และคนเชิดสามคนในชุดดำจับไม้อยู่ด้านหลังเสมอ
```

**3. เสียงและคลิปทดสอบ**
```
ภาพผ่าน ทำเสียงพากย์ ซับ ใส่เสียงฆ้องและเสียงเคาะไม้ตามจังหวะก้าว แล้วเรนเดอร์ 10 วินาทีแรกให้ดู
```

**4. ตัวเต็ม**
```
เรนเดอร์ตัวเต็ม พร้อมปก คำอธิบายคลิป และเครดิต
```

## ตัวอย่างเรื่องที่เหมาะ

1. พระอภัยมณี — เป่าปี่บนเกาะ
2. ขุนช้างขุนแผน — เล่าทีละตอนแบบละครหุ่น
3. นิทานพื้นบ้าน "ศรีธนญชัย" สำหรับเด็ก
