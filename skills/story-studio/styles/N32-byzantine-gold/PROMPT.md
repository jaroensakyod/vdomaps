# คำสั่งสำหรับสไตล์ N32 โมเสกทองไบแซนไทน์

ก๊อปทีละข้อไปวางในผู้ช่วย AI (Claude Code / Codex) แล้วเปลี่ยนข้อความใน [ ]

**1. เรื่องและบท**
```
ใช้สไตล์ N32 โมเสกทองไบแซนไทน์ ทำคลิปเรื่อง [จักรพรรดินีธีโอโดรา] ยาว [45 วินาที] แนวตั้ง — หาข้อมูลพร้อมแหล่งอ้างอิง
เขียนบทให้ดูก่อน บอกด้วยว่าแต่ละฉากมีรูปบุคคลหรืออาคารอะไร ส่วนไหนจะร่วงหลุด ส่วนไหนจะถูกฝังกระเบื้องใหม่
```

**2. ภาพนิ่ง**
```
บทผ่านแล้ว ทำภาพนิ่ง 3 ฉากตามสไตล์ N32 ให้ดู พื้นทองทั้งผนัง กรอบโค้ง รูปบุคคลหันหน้าตรง มีรัศมีใหญ่
ทุกอย่างเป็นกระเบื้องชิ้นเล็ก เส้นขอบเป็นแถวกระเบื้องสีเข้ม
```

**3. เสียงและคลิปทดสอบ**
```
ภาพผ่าน ทำเสียงพากย์ ซับ ใส่เสียงระฆังหรือฆ้องจากคลังเสียง แล้วเรนเดอร์ 10 วินาทีแรกให้ดู
```

**4. ตัวเต็ม**
```
เรนเดอร์ตัวเต็ม พร้อมปก คำอธิบายคลิป และเครดิตแหล่งข้อมูล
```
