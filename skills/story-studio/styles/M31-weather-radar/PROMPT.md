# คำสั่งสำหรับสไตล์ M31 จอเรดาร์อากาศ

ก๊อปทีละข้อไปวางในผู้ช่วย AI (Claude Code / Codex) แล้วเปลี่ยนข้อความใน [ ]

**1. เรื่องและบท**
```
ใช้สไตล์ M31 จอเรดาร์อากาศ ทำคลิปเรื่อง [พายุโซนร้อนปาบึกขึ้นฝั่งนครศรีธรรมราช] ยาว [45 วินาที] แนวตั้ง —
หาข้อมูลเวลา จุดขึ้นฝั่ง และเส้นทางพายุจากแหล่งที่เชื่อถือได้ เขียนบทให้ดูก่อน บอกด้วยว่าจอเรดาร์จะตั้งศูนย์กลางที่ไหนและรัศมีเท่าไร
```

**2. ภาพนิ่ง**
```
บทผ่านแล้ว ทำภาพนิ่ง 3 ฉากตามสไตล์ M31 ให้ดู — พายุยังอยู่ในทะเล ตอนขึ้นฝั่ง และหลังขึ้นฝั่ง
ใส่ป้าย "ภาพจำลอง" บนจอ และเส้นทางพายุเป็นแนวโดยประมาณ
```

**3. เสียงและคลิปทดสอบ**
```
ภาพผ่าน ทำเสียงพากย์ ซับ ใส่เสียงฝน ลมพายุ และฟ้าร้องตอนขึ้นฝั่งจากคลังเสียง แล้วเรนเดอร์ 10 วินาทีแรกให้ดู
```

**4. ตัวเต็ม**
```
เรนเดอร์ตัวเต็ม พร้อมปก คำอธิบายคลิป และเครดิต (กรมอุตุนิยมวิทยา, แผนที่ Natural Earth)
```
