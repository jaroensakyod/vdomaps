เขียนบทให้ดูก่อน พร้อมจุดเส้นทางโดยประมาณ [ลองจิจูด, ละติจูด] และ 4–5 บรรทัดที่จะเขียนลงบัตรบันทึกเดินเรือ
```

**2. ภาพนิ่ง**
```
บทผ่านแล้ว ทำภาพนิ่ง 3 ภาพตามสไตล์ M36 ให้ดู: จอกลมเรืองแสงสีอำพันในขอบทองเหลืองบนแผงสีเขียวเทา ป้ายทองเหลืองด้านบน
ชายฝั่งวาดด้วยเส้นแสง เส้นทางเป็นจุดทีละวัน และบัตรบันทึกเดินเรือเขียนด้วยดินสอเขียนกระจกสีเหลือง
```

**3. เสียงและคลิปทดสอบ**
```
ภาพผ่าน ทำเสียงพากย์และซับ ให้จุดเส้นทางเดินตามวันที่ในคำพากย์ เข็มทิศทองเหลืองหมุนตามทิศเรือ บันทึกบนบัตรเขียนตรงคำพากย์
ใส่เสียงทะเลจากคลังเสียง แล้วเรนเดอร์ 10 วินาทีแรกให้ดู
```

```
