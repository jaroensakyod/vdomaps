**1. เรื่องและบท**
```
ใช้สไตล์ M21 เหรียญรัชกาล ทำคลิปเรื่อง [กษัตริย์ราชวงศ์ปราสาททอง] ยาว [60 วินาที] แนวตั้ง — หาข้อมูลปีครองราชย์
ที่ตรวจสอบได้ เขียนบทให้ดูก่อน บอกด้วยว่าแต่ละรัชกาลใช้เหรียญโลหะอะไร และหน้าเหรียญมีลายอะไร
```

**2. ภาพนิ่ง**
```
บทผ่านแล้ว ทำภาพนิ่ง 3 ฉากตามสไตล์ M21 ให้ดู: เหรียญใหญ่หน้าแผนที่ เหรียญกำลังพลิก และถาดที่มีเหรียญครบ
ห้ามใช้พระบรมรูปหรือเหรียญจริง ใช้ตัวเลขไทย แผนที่ และลายง่าย ๆ เท่านั้น
```

**3. เสียงและคลิปทดสอบ**
```
ภาพผ่าน ทำเสียงพากย์ ซับ ใส่เสียงพลิกเหรียญกับเสียงเหรียญตกถาดเบา ๆ แล้วเรนเดอร์ 10 วินาทีแรกให้ดู
```

**4. ตัวเต็ม**
```
เรนเดอร์ตัวเต็ม พร้อมปก คำอธิบายคลิป และเครดิต
```

## ตัวอย่างเรื่องที่เหมาะ

1. กษัตริย์อยุธยา 5 ราชวงศ์ — แต่ละราชวงศ์เป็นเหรียญโลหะต่างกัน
2. จักรพรรดิราชวงศ์ชิง 10 พระองค์ บนแผนที่จีนที่ขยายและหดลง
3. ฟาโรห์คนสำคัญของอียิปต์ — เหรียญทองกับแผนที่แม่น้ำไนล์ (ใช้ลวดลายใหม่ ไม่เลียนแบบของจริง)
