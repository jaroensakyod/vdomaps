# คำสั่งสำหรับสไตล์ N22 หน้าต่างรถไฟ

ก๊อปทีละข้อไปวางในผู้ช่วย AI (Claude Code / Codex) แล้วเปลี่ยนข้อความใน [ ]

**1. เรื่องและบท**
```
ใช้สไตล์ N22 หน้าต่างรถไฟ ทำคลิปเรื่อง [กรุงเทพฯ 100 ปี ใน 60 วินาที] แนวตั้ง — หาข้อมูล เขียนบทให้ดูก่อน
เลือก 4–6 ปีสำคัญเป็น "สถานี" บอกด้วยว่าแต่ละยุคนอกหน้าต่างเห็นอะไร (บ้าน ตึก ทุ่ง ท้องฟ้า กลางวันหรือกลางคืน)
```

**2. ภาพนิ่ง**
```
บทผ่านแล้ว ทำภาพนิ่งตอนรถไฟผ่านป้ายสถานีแต่ละยุคตามสไตล์ N22 ให้ดู มีหยดฝนบนกระจก ป้ายปีชัดๆ
แผ่นทองเหลืองใต้หน้าต่างบอกปีกับเหตุการณ์
```

**3. เสียงและคลิปทดสอบ**
```
ภาพผ่าน ทำเสียงพากย์ ซับ ใส่เสียงฝนเบาๆ และเสียงระฆังตอนผ่านแต่ละสถานีจากคลังเสียง แล้วเรนเดอร์ 10 วินาทีแรกให้ดู
```

**4. ตัวเต็ม**
```
เรนเดอร์ตัวเต็ม พร้อมปก คำอธิบายคลิป และเครดิต
```

**ใช้เป็นช่วงสรุปยุคในคลิปยาว**
```
ในตอนนี้ ขอช่วงสรุป [จาก พ.ศ. 2310 ถึง 2394] เป็นหน้าต่างรถไฟแบบ N22 ยาว 20 วินาที 4 สถานี แทรกก่อน [ch3]
```
