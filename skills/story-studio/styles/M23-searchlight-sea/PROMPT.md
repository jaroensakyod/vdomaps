# คำสั่งสำหรับสไตล์ M23 ไฟฉายกลางทะเล

**1. เรื่องและบท**
```
ใช้สไตล์ M23 ไฟฉายกลางทะเล ทำคลิปเรื่อง [ยุทธนาวีที่เกาะช้าง] ยาว [60 วินาที] แนวตั้ง — หาข้อมูลเวลาและตำแหน่งเรือ
จากแหล่งที่ตรวจสอบได้ เขียนบทเป็นบันทึกเวลา (เวลา · เหตุการณ์) ให้ดูก่อน บอกด้วยว่าต้องดึงแนวชายฝั่ง OSM ช่วงไหน
```

**2. ภาพนิ่ง**
```
บทผ่านแล้ว ทำภาพนิ่ง 3 ฉากตามสไตล์ M23 ให้ดู: ไฟฉายกวาดหาเป้า พลุส่องสว่าง และกระสุนส่องวิถีเข้าเป้า
แสงเป็นสีขาว-ฟ้าน้ำแข็ง มีสีอุ่นสีเดียวคือพลุกับไฟ ติดป้าย "ภาพจำลอง · ตำแหน่งโดยประมาณ"
```

**3. เสียงและคลิปทดสอบ**
```
ภาพผ่าน ทำเสียงพากย์ ซับ ใส่เสียงทะเล ปืนใหญ่ไกล ๆ และระเบิดตรงจังหวะภาพ แล้วเรนเดอร์ 10 วินาทีแรกให้ดู
```

**4. ตัวเต็ม**
```
เรนเดอร์ตัวเต็ม พร้อมปก คำอธิบายคลิป และเครดิต (OpenStreetMap)
```
