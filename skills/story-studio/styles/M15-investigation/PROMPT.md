**1. เรื่องและบท**
```
ใช้สไตล์ M15 กระดานสืบสวน ทำคลิปเรื่อง [การหายตัวของจิม ทอมป์สัน] ยาว [60 วินาที] แนวตั้ง —
หาข้อเท็จจริงที่ตรวจสอบได้ (ใคร ที่ไหน เมื่อไร) แยกให้ชัดว่าอะไรคือข้อเท็จจริง อะไรคือสมมติฐาน
เขียนบทให้ดูก่อน พร้อมรายการ "การ์ดหลักฐาน" และแหล่งที่มา
```

**2. ภาพนิ่ง**
```

เป็นกระดานไม้ก๊อกใต้แสงโคมไฟตั้งโต๊ะ แผนที่พิมพ์พับปักหมุดทองเหลือง บัตรดัชนีพิมพ์ดีด การ์ดหลักฐานวาดเส้นหมึก
(ไม่ใช้รูปถ่าย ไม่ใช้กระดาษโน้ตกาว) และด้ายขนสัตว์สีแดงขึงระหว่างหมุด
```

**3. เสียงและคลิปทดสอบ**
```
ภาพผ่าน ทำเสียงพากย์ ซับตามคำ ให้การ์ดปักลงและด้ายตึงตรงคำพากย์ ใส่เสียงฝนเบา ๆ จากคลังเสียง
แล้วเรนเดอร์ 10 วินาทีแรกให้ดู
```

**4. ตัวเต็ม**
