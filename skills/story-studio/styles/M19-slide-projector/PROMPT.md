# คำสั่งสำหรับสไตล์ M19 สไลด์ฉายภาพ

ก๊อปทีละข้อไปวางในผู้ช่วย AI (Claude Code / Codex) แล้วเปลี่ยนข้อความใน [ ]

**1. เรื่องและบท**
```
ใช้สไตล์ M19 สไลด์ฉายภาพ ทำคลิปเรื่อง [กรุงเทพฯ ขยายตัวจากเกาะรัตนโกสินทร์] ยาว [60 วินาที] แนวตั้ง —
แบ่งเป็นสไลด์ 3–6 ใบ แต่ละใบคือช่วงเวลาหนึ่ง หาข้อมูลปีและขอบเขตจริงพร้อมแหล่งที่มา เขียนบทให้ดูก่อน
```

**2. ภาพนิ่ง**
```
บทผ่านแล้ว ทำภาพนิ่ง 3 ภาพตามสไตล์ M19 ให้ดู: สไลด์ใบแรก ใบกลาง และใบสุดท้าย
ห้องมืด ม่านกำมะหยี่ จอผ้าดึงลง เครื่องฉายสไลด์ถาดกลม ลำแสงอุ่นมีฝุ่นลอย ภาพดาวเทียมปรับโทนเป็นฟิล์มเก่าทีละยุค เขียนด้วยดินสอเขียนกระจกสีแดง กรอบสไลด์มีลายมือ
```

**3. เสียงและคลิปทดสอบ**
```
ภาพผ่าน ทำเสียงพากย์ ซับตามคำ ให้สไลด์เปลี่ยนพร้อมเสียงคลิกตรงคำพากย์ เส้นดินสอวาดตามคำ แล้วเรนเดอร์ 10 วินาทีแรกให้ดู
```

**4. ตัวเต็ม**
```
เรนเดอร์ตัวเต็มแนวตั้ง พร้อมปก คำอธิบายคลิป แหล่งข้อมูล เครดิตภาพดาวเทียมและ OpenStreetMap
```

**ใช้เป็นฉากพิเศษในคลิปยาว**
```
ในตอนนี้ ขอฉากเครื่องฉายสไลด์แบบ M19 ยาว 12 วินาที เทียบ [ชายฝั่งบางขุนเทียน] สมัยก่อนกับวันนี้ 2 สไลด์ แทรกช่วง [ch3]
```

## ตัวอย่างเรื่องที่เหมาะ

1. กรุงเทพฯ ขยายตัว — จากคลองรอบกรุงถึงวันนี้
2. ชายฝั่งบางขุนเทียนหายไปไหน — ทะเลกินแผ่นดิน
3. สนามบินดอนเมืองถึงสุวรรณภูมิ — เมืองโตตามสนามบิน
