# คำสั่งสำหรับสไตล์ M08 แผนที่กระดาษ ซีรีส์ยาว

ก๊อปทีละข้อไปวางในผู้ช่วย AI (Claude Code / Codex) แล้วเปลี่ยนข้อความใน [ ]

**1. เรื่องและบท**
```
ใช้สไตล์ M08 แผนที่กระดาษ ซีรีส์ยาว ทำซีรีส์ [สามก๊ก] [60] ตอน ตอนละ [70–80 วินาที] แนวตั้งลง Reels
— วางโครงทุกตอนก่อน (ปมเปิด → ปมปิด) แล้วเขียนบทตอนที่ [1] ให้ดู มีประโยคตัวละคร 1–2 ประโยค และช่วงนิยาย vs บันทึก
```

**2. ภาพนิ่ง**
```
บทผ่านแล้ว ทำภาพนิ่ง 3 ฉากตามสไตล์ M08 ให้ดู — ฉากเปิด (การ์ดชื่อเรื่อง) ฉากที่ตัวละครพูด (การ์ดตัวละคร + ป้ายชื่อ)
และการ์ดตอนต่อไป ภาพประกอบวาดด้วยโค้ดเท่านั้น
```

**3. เสียงและคลิปทดสอบ**
```
ภาพผ่าน ทำเสียงผู้เล่าและเสียงตัวละคร ซับ ใส่เสียงกลองและฆ้องจากคลังเสียง แล้วเรนเดอร์ 10 วินาทีแรกให้ดู
```

**4. ตัวเต็ม**
```
เรนเดอร์ตัวเต็มทั้งฉบับ Reels (มีป้ายตอนที่ + การ์ดตอนต่อไป) และฉบับ YouTube 16:9 พร้อมปก คำอธิบายคลิป และเครดิต
```

**ทำตอนถัดไปในซีรีส์เดิม**
```

```
