# คำสั่งสำหรับสไตล์ N26 หน้ากากโขน

ก๊อปทีละข้อไปวางในผู้ช่วย AI (Claude Code / Codex) แล้วเปลี่ยนข้อความใน [ ]

**1. เรื่องและบท**
```
ใช้สไตล์ N26 หน้ากากโขน ทำคลิปเรื่อง [รามเกียรติ์ ตอนศึกไมยราพ] ยาว [60 วินาที] แนวตั้ง — เล่าใหม่ด้วยคำของเราเอง
เขียนบทให้ดูก่อน บอกด้วยว่าแต่ละฉากเป็นหน้ากากตัวไหน หันไปทางไหน และต้องออกแบบหน้ากากใหม่กี่หน้า
```

**2. ภาพนิ่ง**
```
บทผ่านแล้ว ทำภาพนิ่ง 3 ฉากตามสไตล์ N26 ให้ดู หน้ากากใหม่ให้วางลายบน Feat แบบใน kit เพื่อให้หันได้
ให้หน้ากากใหญ่เต็มสองในสามของจอ แสงมาจากซ้าย ข้อความอยู่ฝั่งขวาที่มืด
```

**3. เสียงและคลิปทดสอบ**
```
ภาพผ่าน ทำเสียงพากย์ ซับ ใส่กลองและฆ้องจากคลังเสียง แล้วเรนเดอร์ 10 วินาทีแรกให้ดู
```

**4. ตัวเต็ม**
```
เรนเดอร์ตัวเต็ม พร้อมปก คำอธิบายคลิป และเครดิต
```
