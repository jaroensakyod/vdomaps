# คำสั่งสำหรับสไตล์ M05 แผ่นลอกลายคลองเก่า

ก๊อปทีละข้อไปวางในผู้ช่วย AI (Claude Code / Codex) แล้วเปลี่ยนข้อความใน [ ]

**1. เรื่องและบท**
```
ใช้สไตล์ M05 แผ่นลอกลายคลองเก่า ทำคลิปเรื่อง [คลองกรุงเทพฯ ยุคแรก] ยาว [60 วินาที] แนว[ตั้ง] — หาข้อมูล เขียนบทให้ดูก่อน
แบ่งเป็นแผ่นลอกลายทีละยุค (ไม่เกิน 5 แผ่น) บอกว่าแผ่นไหนลอกคลองอะไร สีดินสออะไร และสายไหนต้องตัดออกเพราะขุดทีหลัง
```

**2. ภาพนิ่ง**
```
บทผ่านแล้ว ดึงภาพ HLS และคลองจาก OSM ตามหัวข้อ Data ใน STYLE.md ของ M05 แก้รายชื่อคลองใน canals.mjs
แล้วทำภาพนิ่ง 3 ฉากให้ดู (แผ่นแรกลอกแม่น้ำ, แผ่นสายเดิมซ้อนทับ, แผ่นที่วงดินสอรอบจุดสำคัญ)
มีเทปกาว เครื่องหมายจัดแนว ไม้บรรทัด ลายมือ และกรอบชื่อแผ่นแบบงานเขียนแบบ
```

**3. เสียงและคลิปทดสอบ**
```
ภาพผ่าน ทำเสียงพากย์ ซับ ให้แผ่นลอกลายแต่ละแผ่นเลื่อนเข้ามาและดินสอเริ่มลากเส้นตรงคำที่พูดชื่อคลอง
ใส่เสียงกระดาษ/ดินสอเบา ๆ จากคลังเสียง แล้วเรนเดอร์ 10 วินาทีแรกให้ดู
```

**4. ตัวเต็ม**
```
เรนเดอร์ตัวเต็ม ทั้งแนวตั้งและแนวนอน พร้อมปก คำอธิบายคลิป และเครดิต NASA / OpenStreetMap
```

## ตัวอย่างเรื่องที่เหมาะ

1. แม่น้ำเจ้าพระยาเคยไหลอ้อม — คลองลัดบางกอกที่กลายเป็นแม่น้ำ
2. คูเมืองกรุงธนบุรีถึงคลองรอบกรุง — เมืองหลวงขยายตามคลอง ทีละแผ่น
3. น้ำท่วมใหญ่ 2485 — ลอกแนวน้ำท่วมทับแผนที่คลองเดิม
