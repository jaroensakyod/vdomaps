# คำสั่งสำหรับสไตล์ M05 คลองและแม่น้ำเมืองเก่าเรืองแสง

ก๊อปทีละข้อไปวางในผู้ช่วย AI (Claude Code / Codex) แล้วเปลี่ยนข้อความใน [ ]

**1. เรื่องและบท**
```
ใช้สไตล์ M05 ทำคลิปเรื่อง [คลองกรุงเทพฯ ยุคแรก] ยาว [60 วินาที] แนว[ตั้ง] — หาข้อมูล เขียนบทให้ดูก่อน
บอกด้วยว่าคลองไหนขุดสมัยไหน และสายไหนต้องตัดออกเพราะขุดทีหลัง
```

**2. ภาพนิ่ง**
```
บทผ่านแล้ว ดึงภาพ HLS และคลองจาก OSM ตามหัวข้อ Data ใน STYLE.md ของ M05 แก้รายชื่อคลองใน canals.mjs
แล้วทำภาพนิ่ง 3 ฉากให้ดู (คลองทั้งหมดเรืองแสง, ไฮไลต์สายเดิม, เพิ่มคลองยุคใหม่)
```

**3. เสียงและคลิปทดสอบ**
```
ภาพผ่าน ทำเสียงพากย์ ซับ ให้คลองแต่ละสายสว่างตรงคำที่พูดชื่อ ใส่เสียงน้ำ/เรือจากคลังเสียง แล้วเรนเดอร์ 10 วินาทีแรกให้ดู
```

**4. ตัวเต็ม**
```
เรนเดอร์ตัวเต็ม ทั้งแนวตั้งและแนวนอน พร้อมปก คำอธิบายคลิป และเครดิต NASA / OpenStreetMap
```

## ตัวอย่างเรื่องที่เหมาะ

1. แม่น้ำเจ้าพระยาเคยไหลอ้อม — คลองลัดบางกอกที่กลายเป็นแม่น้ำ
2. คูเมืองกรุงธนบุรีถึงคลองรอบกรุง — เมืองหลวงขยายตามคลอง
3. น้ำท่วมใหญ่ 2485 — น้ำไหลตามคลองไหนเข้าพระนคร
