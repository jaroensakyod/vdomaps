# คำสั่งสำหรับสไตล์ N24 ภาพทราย

ก๊อปทีละข้อไปวางในผู้ช่วย AI (Claude Code / Codex) แล้วเปลี่ยนข้อความใน [ ]

**1. เรื่องและบท**
```
ใช้สไตล์ N24 ภาพทราย ทำคลิปเรื่อง [ข้าวหนึ่งเม็ดมาจากไหน] ยาว [45 วินาที] แนวตั้ง — หาข้อมูล เขียนบทให้ดูก่อน
แบ่งเป็น 4–6 ภาพ บอกว่าแต่ละภาพวาดด้วยทรายอะไร และภาพไหนเปลี่ยนเป็นภาพไหน (อะไรค้างไว้ อะไรถูกปัดทิ้ง)
```

**2. ภาพนิ่ง**
```
บทผ่านแล้ว ทำภาพนิ่ง 3 ภาพตามสไตล์ N24 ให้ดู ทรายสีน้ำตาลเข้มบนโต๊ะไฟ กรอบทรายรอบวงรีสว่าง
ชื่อเรื่องกับคำบรรยายเขียนลงในทราย
```

**3. เสียงและคลิปทดสอบ**
```
ภาพผ่าน ทำเสียงพากย์ช้าๆ อบอุ่น ซับ ใส่เสียงลมเบาๆ จากคลังเสียง แล้วเรนเดอร์ 10 วินาทีแรกให้ดู
```

**4. ตัวเต็ม**
```
เรนเดอร์ตัวเต็ม พร้อมปก คำอธิบายคลิป และเครดิต
```

**ใช้เป็นช่วงอธิบายในคลิปยาว**
```
ในตอนนี้ ขอช่วงอธิบาย [น้ำขึ้นน้ำลงเกิดจากอะไร] เป็นภาพทรายแบบ N24 ยาว 20 วินาที แทรกก่อน [ch3]
```
