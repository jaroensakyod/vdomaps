# คำสั่งสำหรับสไตล์ N15 งานปักไหม

ก๊อปทีละข้อไปวางในผู้ช่วย AI (Claude Code / Codex) แล้วเปลี่ยนข้อความใน [ ]

**1. เรื่องและบท**
```
ใช้สไตล์ N15 งานปักไหม ทำคลิปเล่านิทาน [ขุนช้างขุนแผน ตอนกำเนิดพลายงาม] ยาว [45 วินาที] แนวตั้ง
หาข้อมูล เขียนบทให้ดูก่อน บอกด้วยว่าแต่ละฉากจะปักอะไรในสะดึง และปักส่วนไหนก่อนหลัง
```

**2. ภาพนิ่ง**
```
บทผ่านแล้ว ทำภาพนิ่ง 3 ฉากตามสไตล์ N15 ให้ดู ทุกชิ้นต้องเป็นด้ายปักแบบเดินเส้นไหมเต็ม มีเงาเงาวาว
เส้นขอบเป็นดิ้นทอง มีเข็มกับด้ายอยู่ตรงที่กำลังปัก
```

**3. เสียงและคลิปทดสอบ**
```
ภาพผ่าน ทำเสียงพากย์ ซับ ให้แต่ละชิ้น "ปักขึ้นมา" ตรงกับคำพากย์ เสียงเข็มเบา ๆ ใต้เสียงพากย์
แล้วเรนเดอร์ 10 วินาทีแรกให้ดู
```

**4. ตัวเต็ม**
```
เรนเดอร์ตัวเต็ม พร้อมปก คำอธิบายคลิป และเครดิต
```
