# คำสั่งสำหรับสไตล์ M30 แผนที่พับกระดาษ

ก๊อปทีละข้อไปวางในผู้ช่วย AI (Claude Code / Codex) แล้วเปลี่ยนข้อความใน [ ]

**1. เรื่องและบท**
```
ใช้สไตล์ M30 แผนที่พับกระดาษ ทำคลิปเรื่อง [การเดินทางของสุนทรภู่ในนิราศภูเขาทอง] ยาว [45 วินาที] แนวตั้ง —
หาข้อมูลเส้นทางและสถานที่จริงพร้อมแหล่งที่มา เขียนบทให้ดูก่อน บอกด้วยว่าจะมีชิ้นกระดาษพับอะไรตั้งขึ้นที่จุดไหนบ้าง
```

**2. ภาพนิ่ง**
```
บทผ่านแล้ว ทำภาพนิ่ง 3 ฉากตามสไตล์ M30 ให้ดู — แผนที่ยังพับอยู่ กำลังคลี่ และเรือกระดาษกลางทาง
```

**3. เสียงและคลิปทดสอบ**
```
ภาพผ่าน ทำเสียงพากย์ ซับ ใส่เสียงกระดาษพับ เสียงน้ำและเรือจากคลังเสียง แล้วเรนเดอร์ 10 วินาทีแรกให้ดู
```

**4. ตัวเต็ม**
```
เรนเดอร์ตัวเต็ม พร้อมปก คำอธิบายคลิป และเครดิต (© OpenStreetMap contributors)
```

## ตัวอย่างเรื่องที่เหมาะ

1. รถไฟสายเหนือ — จากกรุงเทพฯ ถึงเชียงใหม่ ผ่านอุโมงค์ขุนตาน
2. เส้นทางเสด็จประพาสต้น — ล่องเรือตามคลองและแม่น้ำภาคกลาง
3. ไปเที่ยวญี่ปุ่นแบบประหยัด — จากโตเกียวถึงเกียวโตด้วยรถไฟ (ตัวอย่าง)
