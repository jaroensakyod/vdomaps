# คำสั่งสำหรับสไตล์ M10 ข่าวอากาศ แนวปะทะอากาศเย็น

ก๊อปทีละข้อไปวางในผู้ช่วย AI (Claude Code / Codex) แล้วเปลี่ยนข้อความใน [ ]

**1. เรื่องและบท**
```
ใช้สไตล์ M10 ข่าวอากาศ ทำคลิปเรื่อง [มวลอากาศเย็นระลอกใหม่ปลายปี] ยาว [60 วินาที] แนวตั้ง — หาข้อมูล เขียนบทให้ดูก่อน
บอกด้วยว่าตัวเลขไหนเป็นข้อมูลจริง ตัวไหนเป็นภาพจำลอง และต้องดึงภาพดาวเทียมช่วงไหน
```

**2. ภาพนิ่ง**
```
บทผ่านแล้ว ดึงภาพดาวเทียมตามที่ STYLE.md บอก แล้วทำภาพนิ่ง 3 ฉากตามสไตล์ M10 ให้ดู
มีมวลอากาศ แนวปะทะ หมุดเมืองพร้อมอุณหภูมิ และการ์ดหัวข่าว
```

**3. เสียงและคลิปทดสอบ**
```
ภาพผ่าน ทำเสียงพากย์แบบผู้ประกาศข่าวอากาศ ซับ ใส่เสียงลมจากคลังเสียง แล้วเรนเดอร์ 10 วินาทีแรกให้ดู
```

**4. ตัวเต็ม**
```
เรนเดอร์ตัวเต็ม พร้อมปก คำอธิบายคลิป และเครดิตภาพดาวเทียม
```

## ตัวอย่างเรื่องที่เหมาะ

1. ลมหนาวมาแล้ว — ความกดอากาศสูงจากจีนแผ่ลงมาถึงไทย อุณหภูมิลดกี่องศา
2. มรสุมตะวันตกเฉียงใต้เริ่มต้นฤดูฝน — ฝนเคลื่อนจากทะเลอันดามันเข้าฝั่ง
3. คลื่นความร้อนเดือนเมษายน — ทำไมภาคเหนือร้อนเกิน 44 องศา (สลับสีเป็นโทนร้อน)
