# คำสั่งสำหรับสไตล์ M26 แผนที่ไม้แกะสลัก

ก๊อปทีละข้อไปวางในผู้ช่วย AI (Claude Code / Codex) แล้วเปลี่ยนข้อความใน [ ]

**1. เรื่องและบท**
```
ใช้สไตล์ M26 แผนที่ไม้แกะสลัก ทำคลิปเรื่อง [ประวัติเมืองน่าน] ยาว [45 วินาที] แนวตั้ง — หาข้อมูลพร้อมแหล่งอ้างอิง
เขียนบทให้ดูก่อน บอกด้วยว่าต้องแกะแม่น้ำสายไหน เมืองไหนเป็นดอกกลม และเมืองไหนจะปิดทอง
```

**2. ภาพนิ่ง**
```
บทผ่านแล้ว ทำภาพนิ่ง 3 ภาพตามสไตล์ M26: ตอนขุดพื้นรอบแผ่นดิน ตอนสิ่วกำลังแกะแม่น้ำ และตอนปิดทองเมืองสำคัญ
ชื่อเมืองต้องอยู่บนแผ่นดินที่นูน ไม่อยู่บนพื้นที่ขุด
```

**3. เสียงและคลิปทดสอบ**
```
ภาพผ่าน ทำเสียงพากย์ ซับ ใส่เสียงสิ่วกระทบไม้ตอนแกะ และเสียงบรรยากาศป่าเบา ๆ จากคลังเสียง แล้วเรนเดอร์ 10 วินาทีแรกให้ดู
```

**4. ตัวเต็ม**
```
เรนเดอร์ตัวเต็ม พร้อมปก คำอธิบายคลิป และเครดิตแผนที่กับแหล่งข้อมูล
```

## ตัวอย่างเรื่องที่เหมาะ

1. พญามังรายสร้างล้านนา — เชียงราย หริภุญไชย เชียงใหม่ (ตัวอย่างในเดโม)
2. เมืองสามหมอก แม่ฮ่องสอน — ทางช้างขนไม้ข้ามเขา
3. วัดสำคัญริมแม่น้ำน่าน — ตามลำน้ำจากต้นน้ำถึงปากน้ำโพ
