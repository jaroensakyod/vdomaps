# คำสั่งสำหรับสไตล์ N35 หนังตะลุงสี

ก๊อปทีละข้อไปวางในผู้ช่วย AI (Claude Code / Codex) แล้วเปลี่ยนข้อความใน [ ]

**1. เรื่องและบท**
```
ใช้สไตล์ N35 หนังตะลุงสี ทำคลิปเรื่อง [ทำไมทุเรียนถึงแพง] ยาว [45 วินาที] แนวตั้ง — หาข้อมูล เขียนบทเป็นบทสนทนา
ของตัวตลกสองตัวให้ดูก่อน บอกด้วยว่าต้องออกแบบตัวหนังใหม่ตัวไหนบ้าง
```

**2. ภาพนิ่ง**
```
บทผ่านแล้ว ทำภาพนิ่ง 3 ฉากตามสไตล์ N35 ให้ดู ตัวหนังสีโปร่งแสง มีรูฉลุ ไม้เชิด และขากรรไกรขยับได้แบบใน kit
```

**3. เสียงและคลิปทดสอบ**
```
ภาพผ่าน ทำเสียงพากย์ (แยกเสียงตัวละครสองตัว) ซับ ใส่เสียงโหม่งตอนเปิด แล้วเรนเดอร์ 10 วินาทีแรกให้ดู
```

**4. ตัวเต็ม**
```
เรนเดอร์ตัวเต็ม พร้อมปก คำอธิบายคลิป และเครดิต
```

**ใช้เป็นฉากพิเศษในคลิปยาว**
```
ในตอนนี้ ขอฉากตัวตลกหนังตะลุงแบบ N35 คุยสรุปเรื่อง [ภาษีใหม่] ยาว 10 วินาที แทรกท้ายช่วง [ch5]
```

## ตัวอย่างเรื่องที่เหมาะ

1. หนังตะลุงคืออะไร — นายหนังคนเดียวพากย์ทุกตัว
2. ตำนานเมืองนครศรีธรรมราช เล่าแบบตลกปักษ์ใต้
3. ข่าวเศรษฐกิจประจำสัปดาห์ ให้ตัวตลกสองตัวเถียงกัน
