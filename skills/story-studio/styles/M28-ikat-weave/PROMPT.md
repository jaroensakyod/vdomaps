# คำสั่งสำหรับสไตล์ M28 แผนที่ผ้ามัดหมี่

ก๊อปทีละข้อไปวางในผู้ช่วย AI (Claude Code / Codex) แล้วเปลี่ยนข้อความใน [ ]

**1. เรื่องและบท**
```
ใช้สไตล์ M28 แผนที่ผ้ามัดหมี่ ทำคลิปเรื่อง [กบฏผู้มีบุญ อีสาน พ.ศ. 2444] ยาว [45 วินาที] แนวตั้ง — หาข้อมูลพร้อมแหล่งอ้างอิง
เขียนบทให้ดูก่อน บอกด้วยว่าแต่ละพื้นที่ย้อมสีอะไร ใช้ลายมัดหมี่แบบไหน และเมืองไหนจะทอเป็นลายข้าวหลามตัด
```

**2. ภาพนิ่ง**
```
บทผ่านแล้ว ทำภาพนิ่ง 3 ภาพตามสไตล์ M28: ตอนเริ่มทอ (เห็นกี่ ฟืม และกระสวย) ตอนทอได้ครึ่งผืน และตอนทอเสร็จ
ขอบสีต้องเป็นขั้นบันไดและซึมไปตามแนวด้ายพุ่ง ไม่ใช่งานปัก
```

**3. เสียงและคลิปทดสอบ**
```
ภาพผ่าน ทำเสียงพากย์ ซับ ใส่เสียงฟืมกระทบทุกครั้งที่ทอหนึ่งเส้น และเสียงลมเบา ๆ จากคลังเสียง แล้วเรนเดอร์ 10 วินาทีแรกให้ดู
```

**4. ตัวเต็ม**
```
เรนเดอร์ตัวเต็ม พร้อมปก คำอธิบายคลิป และเครดิตแผนที่กับแหล่งข้อมูล
```

## ตัวอย่างเรื่องที่เหมาะ

1. ล้านช้าง — เจ้าฟ้างุ้ม เชียงทอง เวียงจันทน์ พระธาตุหลวง (ตัวอย่างในเดโม)
2. เมืองโบราณลุ่มน้ำมูล-ชี — พิมาย พนมรุ้ง และเส้นทางสู่นครธม
3. ผ้าไหมสุรินทร์ — หมู่บ้านทอผ้าริมลำน้ำมูล
