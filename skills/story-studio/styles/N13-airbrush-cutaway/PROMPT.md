# คำสั่งสำหรับสไตล์ N13 ภาพตัดพ่นสี

ก๊อปทีละข้อไปวางในผู้ช่วย AI (Claude Code / Codex) แล้วเปลี่ยนข้อความใน [ ]

**1. เรื่องและบท**
```
ใช้สไตล์ N13 ภาพตัดพ่นสี ทำคลิปอธิบายเรื่อง [ภูเขาไฟระเบิดได้อย่างไร] ยาว [45 วินาที] แนวตั้ง
หาข้อมูลจากแหล่งที่เชื่อถือได้ (เช่น USGS, NASA) เขียนบทให้ดูก่อน บอกด้วยว่าแต่ละฉากจะผ่าภาพตัดตรงไหน
และมีหมายเลขชี้ส่วนใดบ้าง
```

**2. ภาพนิ่ง**
```
บทผ่านแล้ว ทำภาพนิ่ง 3 ฉากตามสไตล์ N13 ให้ดู ภาพตัดต้องไล่สีแบบพ่นสี มีแสงเรือง หมายเลขชี้ และป้ายชื่อตัวหนา
ใส่ "ภาพประกอบ" และที่มาของข้อมูลมุมล่าง
```

**3. เสียงและคลิปทดสอบ**
```
ภาพผ่าน ทำเสียงพากย์ ซับ ใส่เสียงประกอบจากคลังเสียงตรงจังหวะเหตุการณ์ (เบาใต้เสียงพากย์)
แล้วเรนเดอร์ 10 วินาทีแรกให้ดู
```

**4. ตัวเต็ม**
```
เรนเดอร์ตัวเต็ม พร้อมปก คำอธิบายคลิป และเครดิตแหล่งข้อมูล
```

## ตัวอย่างเรื่องที่เหมาะ

1. ทำไมพื้นดินถึงสั่น — รอยเลื่อน แรงสะสม หินดีดกลับ
2. ภูเขาไฟระเบิดได้อย่างไร — ผ่าภูเขาไฟให้เห็นห้องแมกมา
3. ฟ้าผ่าเกิดจากอะไร — ผ่าเมฆฝนฟ้าคะนองให้เห็นประจุ
