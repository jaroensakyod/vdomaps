# คำสั่งสำหรับสไตล์ N05 หนังใหญ่

ก๊อปทีละข้อไปวางในผู้ช่วย AI (Claude Code / Codex) แล้วเปลี่ยนข้อความใน [ ]

**1. เรื่องและบท**
```
ใช้สไตล์ N05 หนังใหญ่ ทำคลิปเรื่อง [ศึกบางระจัน] ยาว [45 วินาที] แนวตั้ง — หาข้อมูล เขียนบทให้ดูก่อน
บอกด้วยว่าแต่ละฉากต้องวาดตัวหนังใหม่ตัวไหนบ้าง
```

**2. ภาพนิ่ง**
```
บทผ่านแล้ว ทำภาพนิ่ง 3 ฉากตามสไตล์ N05 ให้ดู ตัวหนังใหม่ให้มีลายฉลุและขอบกนกแบบใน kit
```

**3. เสียงและคลิปทดสอบ**
```
ภาพผ่าน ทำเสียงพากย์ ซับ ใส่เสียงปี่พาทย์หรือกลองจากคลังเสียง แล้วเรนเดอร์ 10 วินาทีแรกให้ดู
```

**4. ตัวเต็ม**
```
เรนเดอร์ตัวเต็ม พร้อมปก คำอธิบายคลิป และเครดิต
```

**ใช้เป็นฉากพิเศษในคลิปยาว**
```
ในตอนนี้ ขอฉาก [การรบที่ประตูเมือง] เป็นหนังใหญ่แบบ N05 ยาว 8 วินาที แทรกกลางช่วง [ch4]
```

## ตัวอย่างเรื่องที่เหมาะ

1. ศึกบางระจัน — ชาวบ้านตั้งค่ายสู้ทัพพม่า
2. พระรามข้ามสมุทร — ตอนจองถนนจากรามเกียรติ์
3. ยุทธนาวีที่เกาะช้าง เล่าแบบหนังใหญ่ (เรือรบเป็นตัวหนัง)
