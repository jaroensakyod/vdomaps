# คำสั่งสำหรับสไตล์ N11 ควิซท้ายบท (เกมโชว์นีออน)

ก๊อปทีละข้อไปวางในผู้ช่วย AI (Claude Code / Codex) แล้วเปลี่ยนข้อความใน [ ]

**1. เรื่องและบท**
```
ใช้สไตล์ N11 ควิซท้ายบท (เกมโชว์นีออน) ทำคลิปควิซเรื่อง [สมเด็จพระนเรศวร] ยาว [45 วินาที] แนวตั้ง —
ทำคำถาม 3 ข้อ ข้อละ 3–4 ตัวเลือก (ตัวเลือกละไม่เกิน 14 ตัวอักษร) พร้อมเฉลยหนึ่งบรรทัดและแหล่งอ้างอิงของคำตอบ ให้ดูก่อน
```

**2. ภาพนิ่ง**
```
คำถามผ่านแล้ว ทำภาพนิ่งตามสไตล์ N11 ให้ดู 2 ภาพต่อข้อ (ตอนนับถอยหลังด้วยวงหลอดไฟ และตอนเฉลยมีแฟลชกับกระดาษสี)
เวทีมืด ป้ายคำถามมีหลอดไฟวิ่งรอบ ตัวอักษรเป็นหลอดนีออน
```

**3. เสียงและคลิปทดสอบ**
```
ภาพผ่าน ทำเสียงพากย์อ่านคำถาม นับ 3-2-1 แล้วเฉลยตรงจังหวะ ใส่เสียงติ๊กและเสียงบัซเซอร์ตอนเฉลย แล้วเรนเดอร์ข้อแรกให้ดู
```

**4. ตัวเต็ม**
```
เรนเดอร์ตัวเต็ม ทั้งแนวตั้งและแนวนอน พร้อมปก และคำอธิบายคลิปที่มีแหล่งอ้างอิงของคำตอบ
```

**ใช้เป็นช่วงควิซในคลิปยาว**
```
ในตอนนี้ ขอช่วงควิซแบบ N11 หนึ่งข้อท้ายช่วง [ch3] ตัดเข้าเวทีเกมโชว์ 8–10 วินาที แล้วตัดกลับเข้าเรื่อง
```

## ตัวอย่างเรื่องที่เหมาะ

1. ควิซประวัติศาสตร์ไทย 3 ข้อ — ทายปีเสียกรุงและปีสร้างกรุง
2. ทายกันหน่อย ท้ายตอนยุทธหัตถี — ใครชนะ และชนะที่ไหน
3. ภูมิศาสตร์ไทย — แม่น้ำสายไหนยาวที่สุด
