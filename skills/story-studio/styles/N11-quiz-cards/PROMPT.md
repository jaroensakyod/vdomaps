# คำสั่งสำหรับสไตล์ N11 ควิซท้ายบท

ก๊อปทีละข้อไปวางในผู้ช่วย AI (Claude Code / Codex) แล้วเปลี่ยนข้อความใน [ ]

**1. เรื่องและบท**
```
ใช้สไตล์ N11 ทำคลิปควิซเรื่อง [สมเด็จพระนเรศวร] ยาว [45 วินาที] แนวตั้ง — ทำคำถาม 3 ข้อ ข้อละ 3–4 ตัวเลือก
พร้อมเฉลยหนึ่งบรรทัดและแหล่งอ้างอิงของคำตอบ ให้ดูก่อน
```

**2. ภาพนิ่ง**
```
คำถามผ่านแล้ว ทำภาพนิ่งการ์ดควิซตามสไตล์ N11 ให้ดู 2 ภาพต่อข้อ (ตอนนับถอยหลัง และตอนเฉลย)
```

**3. เสียงและคลิปทดสอบ**
```
ภาพผ่าน ทำเสียงพากย์อ่านคำถาม นับ 3-2-1 แล้วเฉลยตรงจังหวะ ใส่เสียงติ๊กและเสียงเฉลย แล้วเรนเดอร์ข้อแรกให้ดู
```

**4. ตัวเต็ม**
```
เรนเดอร์ตัวเต็ม ทั้งแนวตั้งและแนวนอน พร้อมปก และคำอธิบายคลิปที่มีแหล่งอ้างอิงของคำตอบ
```

**ใช้เป็นช่วงควิซในคลิปยาว**
```
ในตอนนี้ ขอควิซแบบ N11 หนึ่งข้อท้ายช่วง [ch3] วางทับแผนที่ตรงตำแหน่งกรอบภาพประกอบ ไม่ต้องมีพื้นหลัง
```

## ตัวอย่างเรื่องที่เหมาะ

1. ควิซประวัติศาสตร์ไทย 3 ข้อ — ทายปีเสียกรุงและปีสร้างกรุง
2. ทายกันหน่อย ท้ายตอนยุทธหัตถี — ใครชนะ และชนะที่ไหน
3. ภูมิศาสตร์ไทย — แม่น้ำสายไหนยาวที่สุด
