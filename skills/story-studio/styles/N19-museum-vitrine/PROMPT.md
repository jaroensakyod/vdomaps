# คำสั่งสำหรับสไตล์ N19 ตู้จัดแสดง

ก๊อปทีละข้อไปวางในผู้ช่วย AI (Claude Code / Codex) แล้วเปลี่ยนข้อความใน [ ]

**1. เรื่องและบท**
```
ใช้สไตล์ N19 ตู้จัดแสดง ทำคลิปเรื่อง [ดาบญี่ปุ่นของออกญาเสนาภิมุข] ยาว [45 วินาที] แนวตั้ง — หาข้อมูล เขียนบทให้ดูก่อน
บอกด้วยว่าจะวาดวัตถุชิ้นไหน และจุดชี้ 3 จุดคืออะไร พร้อมแหล่งข้อมูล
```

**2. ภาพนิ่ง**
```
บทผ่านแล้ว ทำภาพนิ่ง 3 ภาพตามสไตล์ N19 ให้ดู วัตถุวาดด้วยโค้ด หมุนบนแท่น มีป้ายหมายเลขบนแท่นขาว
```

**3. เสียงและคลิปทดสอบ**
```
ภาพผ่าน ทำเสียงพากย์ ซับ ให้จุดชี้ขึ้นตรงคำพูด แล้วเรนเดอร์ 10 วินาทีแรกให้ดู
```

**4. ตัวเต็ม**
```
เรนเดอร์ตัวเต็ม พร้อมปก คำอธิบายคลิป และเครดิต
```

2. กลองมโหระทึก — กลองสำริดอายุนับพันปี
3. ปืนใหญ่พญาตานี — ปืนใหญ่หน้ากระทรวงกลาโหม
