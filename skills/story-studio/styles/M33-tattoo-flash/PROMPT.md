**1. เรื่องและบท**
```
ใช้สไตล์ M33 แผนที่ลายสัก ทำคลิปเรื่อง [การเดินเรือของเจิ้งเหอ] ยาว [45 วินาที] แนวตั้ง — หาข้อมูลพร้อมแหล่งที่มา
เขียนบทให้ดูก่อน และบอกว่าแต่ละจุดบนเส้นทางจะใช้ลายสักรูปอะไร (นกนางแอ่น สมอ ดาว กุหลาบ เรือ หัวใจ) กับป้ายริบบิ้นข้อความอะไร
```

**2. ภาพนิ่ง**
```
บทผ่านแล้ว ทำภาพนิ่ง 3 ภาพตามสไตล์ M33 ให้ดู: แผ่นลายสักบนกระดาษเก่าที่ปักหมุดไว้บนผนัง เส้นดำหนา สีแดง เขียว เหลือง ดำ
แผนที่อยู่ในวงเชือก เส้นทางเป็นเส้นประแดงหนา ลายสักรอบแผนที่พร้อมป้ายริบบิ้นชื่อสถานที่ ลายใหม่ให้วาดเองตามแบบใน kit
```

**3. เสียงและคลิปทดสอบ**
```
ภาพผ่าน ทำเสียงพากย์และซับ ให้ลายสักแต่ละลายลงเส้นดำก่อนแล้วลงสีตรงคำพากย์ ใส่เสียงทะเลและเสียงเรือจากคลังเสียง
แล้วเรนเดอร์ 10 วินาทีแรกให้ดู
```

**4. ตัวเต็ม**
