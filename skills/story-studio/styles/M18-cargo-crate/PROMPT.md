# คำสั่งสำหรับสไตล์ M18 ลังสินค้า

ก๊อปทีละข้อไปวางในผู้ช่วย AI (Claude Code / Codex) แล้วเปลี่ยนข้อความใน [ ]

**1. เรื่องและบท**
```
ใช้สไตล์ M18 ลังสินค้า ทำคลิปเรื่อง [ทุเรียนไทยไปจีน] ยาว [60 วินาที] แนวตั้ง — หาข้อมูลเส้นทางขนส่ง สินค้า
และราคาจริงพร้อมแหล่งที่มา เขียนบทให้ดูก่อน พร้อมตาราง [ท่าเรือต้นทาง, ปลายทาง, สินค้า, ราคา, แหล่งข้อมูล]
```

**2. ภาพนิ่ง**
```
บทผ่านแล้ว ทำภาพนิ่ง 3 ภาพตามสไตล์ M18 ให้ดู: ตอนเปิดเรื่อง ตอนเส้นทางแรก และตอนลังสินค้าซ้อนครบ
หน้าลังไม้ แผนที่พ่นสีผ่านแผ่นฉลุ เส้นทางเป็นเส้นประสีแดง สินค้าเป็นลังเล็กติดฉลากตรายาง ราคาเป็นป้ายกระดาษผูกเชือกห้อยจากตะปู
```

**3. เสียงและคลิปทดสอบ**
```
ภาพผ่าน ทำเสียงพากย์ ซับตามคำ ให้ลังเลื่อนเข้ามาซ้อนและป้ายราคาห้อยลงตามคำพากย์ ใส่เสียงไม้กระทบและเสียงเรือ แล้วเรนเดอร์ 10 วินาทีแรกให้ดู
```

**4. ตัวเต็ม**
```
เรนเดอร์ตัวเต็มแนวตั้ง พร้อมปก คำอธิบายคลิป แหล่งข้อมูลราคา และเครดิตแผนที่
```

**ใช้เป็นฉากพิเศษในคลิปยาว**
```
ในตอนนี้ ขอฉากลังสินค้าแบบ M18 ยาว 12 วินาที แสดงสินค้า [เครื่องเทศ] จาก [มะละกา] ไป [ลิสบอน] พร้อมราคา แทรกช่วง [ch4]
```

## ตัวอย่างเรื่องที่เหมาะ

1. ข้าวไทยไปไหนบ้าง — ปลายทางส่งออกและราคาต่อตัน
2. เส้นทางเครื่องเทศ — พริกไทยจากมะละกาถึงยุโรป
3. ทำไมทุเรียนแพง — จากสวนจันทบุรีถึงตลาดจีน
