# คำสั่งสำหรับสไตล์ N09 การ์ดหลักฐาน (หนังสือพิมพ์ตัดข่าว)

ก๊อปทีละข้อไปวางในผู้ช่วย AI (Claude Code / Codex) แล้วเปลี่ยนข้อความใน [ ]

**1. เรื่องและบท**
```
ใช้สไตล์ N09 การ์ดหลักฐาน (หนังสือพิมพ์ตัดข่าว) ทำคลิปเรื่อง [พันท้ายนรสิงห์มีตัวตนจริงไหม] ยาว [60 วินาที] แนวตั้ง —
หาข้อมูลจากหลายฝ่าย ทำตาราง "หลักฐานไหนพูดว่าอะไร" พร้อมระดับหลักฐาน แล้วเขียนบทให้ดูก่อน
บอกพาดหัวหน้าหนึ่งของแต่ละช่วง และชื่อหนังสือพิมพ์สมมติบนหัวกระดาษ
```

**2. ภาพนิ่ง**
```
บทผ่านแล้ว ทำภาพนิ่ง 3 ช่วงตามสไตล์ N09 ให้ดู (เช่น ข่าวตัดสองคอลัมน์เทียบสองฝ่าย ไทม์ไลน์ และข่าวตัดสี่ฝ่ายติ๊กถูก)
กระดาษหนังสือพิมพ์สีเทา ตัวอักษรมีเชิง ขอบข่าวตัดเป็นรอยกรรไกร วงและขีดเส้นใต้ด้วยดินสอแดง
ทุกข่าวตัดต้องบอกชื่อหลักฐาน
```

**3. เสียงและคลิปทดสอบ**
```
ภาพผ่าน ทำเสียงพากย์ ซับ ให้รอยดินสอแดงวาดขึ้นตรงคำพูด ใส่เสียงเบา ๆ ตอนติ๊กถูกและตอนเขียนโน้ต
แล้วเรนเดอร์ 10 วินาทีแรกให้ดู
```

**4. ตัวเต็ม**
```
เรนเดอร์ตัวเต็ม พร้อมปก คำอธิบายคลิป และรายการแหล่งอ้างอิง
```

## ตัวอย่างเรื่องที่เหมาะ

1. พระเจ้าตากสิ้นพระชนม์วันไหน — หลักฐานไทย จีน เวียดนาม ฝรั่งเศส ว่าอย่างไร
2. ยุทธหัตถีจบด้วยง้าว หอก หรือปืน — พงศาวดารแต่ละฝ่ายเล่าต่างกัน
3. ศรีปราชญ์มีตัวตนจริงไหม — ตำนานกับหลักฐานร่วมสมัย
