# คำสั่งสำหรับสไตล์ N28 ไซยาโนไทป์

ก๊อปทีละข้อไปวางในผู้ช่วย AI (Claude Code / Codex) แล้วเปลี่ยนข้อความใน [ ]

**1. เรื่องและบท**
```
ใช้สไตล์ N28 ไซยาโนไทป์ ทำคลิปเรื่อง [ใครคิดค้นหลอดไฟ] ยาว [60 วินาที] แนวตั้ง — หาข้อมูลพร้อมแหล่งอ้างอิง
เขียนบทให้ดูก่อน และบอกว่าแต่ละฉากจะ "พิมพ์" วัตถุอะไรเป็นภาพขาวบนกระดาษสีน้ำเงิน
```

**2. ภาพนิ่ง**
```
บทผ่านแล้ว ทำภาพนิ่ง 3 ฉากตามสไตล์ N28 ให้ดู ใช้ Print และ Sheet จาก kit วาดรูปทรงวัตถุใหม่เป็นเงาขาว
ให้ภาพหนึ่งอยู่กลางจังหวะล้างน้ำ (ครึ่งบนน้ำเงิน ครึ่งล่างยังเป็นสีเหลือง)
```

**3. เสียงและคลิปทดสอบ**
```
ภาพผ่าน ทำเสียงพากย์ ซับ ใส่เสียงแปรงปัด เสียงน้ำตอนล้างภาพ แล้วเรนเดอร์ 10 วินาทีแรกให้ดู
```

**4. ตัวเต็ม**
```
เรนเดอร์ตัวเต็ม พร้อมปก คำอธิบายคลิป และแหล่งข้อมูล
```

## ตัวอย่างเรื่องที่เหมาะ

1. แอนนา แอตกินส์ กับหนังสือภาพสาหร่ายเล่มแรก
2. พืชสมุนไพรไทย 5 ชนิด เล่าทีละใบ พิมพ์เป็นภาพขาวบนกระดาษน้ำเงิน
3. กุญแจ ฟันเฟือง หลอดไฟ — สิ่งประดิษฐ์ที่เปลี่ยนโลก ทีละชิ้น
