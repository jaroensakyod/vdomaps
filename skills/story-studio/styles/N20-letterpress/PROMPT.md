# คำสั่งสำหรับสไตล์ N20 ตัวเรียงพิมพ์

ก๊อปทีละข้อไปวางในผู้ช่วย AI (Claude Code / Codex) แล้วเปลี่ยนข้อความใน [ ]

**1. เรื่องและบท**
```
ใช้สไตล์ N20 ตัวเรียงพิมพ์ ทำคลิปเรื่อง [สถิติแม่น้ำเจ้าพระยา] ยาว [45 วินาที] แนวตั้ง — หาข้อมูล เขียนบทให้ดูก่อน
แต่ละฉากมีตัวเลขใหญ่ 1 ตัว บอกที่มาของตัวเลขทุกตัว
```

**2. ภาพนิ่ง**
```
บทผ่านแล้ว ทำภาพนิ่ง 3 แผ่นตามสไตล์ N20 ให้ดู ตัวเลขเป็นตัวไม้ หมึกไม่เรียบ มีรอยกดบนกระดาษ
```

**3. เสียงและคลิปทดสอบ**
```
ภาพผ่าน ทำเสียงพากย์ ซับ ให้แท่นพิมพ์กดลงตรงคำที่พูดตัวเลข แล้วเรนเดอร์ 10 วินาทีแรกให้ดู
```

**4. ตัวเต็ม**
```
เรนเดอร์ตัวเต็ม พร้อมปก คำอธิบายคลิป และเครดิต
```
