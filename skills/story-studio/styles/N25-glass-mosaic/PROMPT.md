# คำสั่งสำหรับสไตล์ N25 กระจกเกรียบ

ก๊อปทีละข้อไปวางในผู้ช่วย AI (Claude Code / Codex) แล้วเปลี่ยนข้อความใน [ ]

**1. เรื่องและบท**
```
ใช้สไตล์ N25 กระจกเกรียบ ทำคลิปเรื่อง [ตำนานพระธาตุดอยสุเทพ] ยาว [60 วินาที] แนวตั้ง — หาข้อมูลพร้อมแหล่งอ้างอิง
เขียนบทให้ดูก่อน บอกด้วยว่าแต่ละฉากในหน้าบันจะเป็นภาพอะไร (พื้นกระจกสีอะไร ลายปูนปั้นปิดทองเป็นอะไร)
```

**2. ภาพนิ่ง**
```
บทผ่านแล้ว ทำภาพนิ่ง 3 ฉากตามสไตล์ N25 ให้ดู ใช้ Wall กับ GiltMass จาก kit ภาพในหน้าบันเป็นกระจกทีละชิ้น
ตัวเอกเป็นปูนปั้นปิดทอง ให้ภาพหนึ่งอยู่กลางจังหวะกระจกพลิกเปลี่ยนฉาก
```

**3. เสียงและคลิปทดสอบ**
```
ภาพผ่าน ทำเสียงพากย์ ซับ ใส่เสียงฆ้องตอนเปลี่ยนภาพจากคลังเสียง แล้วเรนเดอร์ 10 วินาทีแรกให้ดู
```

**4. ตัวเต็ม**
```
เรนเดอร์ตัวเต็ม พร้อมปก คำอธิบายคลิป และแหล่งข้อมูล
```

## ตัวอย่างเรื่องที่เหมาะ

1. ตำนานพระแก้วมรกต — จากเชียงรายถึงกรุงเทพฯ
2. ตำนานพระธาตุดอยสุเทพ — ช้างเผือกเดินขึ้นดอย
3. เรือพระที่นั่งสุพรรณหงส์ — ลวดลายหัวเรือเล่าด้วยกระจกและทอง
