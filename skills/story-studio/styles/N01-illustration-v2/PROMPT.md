# คำสั่งสำหรับสไตล์ N01 ภาพประกอบ v2

ก๊อปทีละข้อไปวางในผู้ช่วย AI (Claude Code / Codex) แล้วเปลี่ยนข้อความใน [ ]

**1. เรื่องและบท**
```
ใช้สไตล์ N01 ภาพประกอบ v2 ทำคลิปเรื่อง [ศึกบางระจัน] ยาว [60 วินาที] แนวตั้ง — หาข้อมูล เขียนบทให้ดูก่อน
แบ่งเป็นฉากละ 3–4 วินาที บอกด้วยว่าแต่ละฉากใช้ฉากไหนใน kit หรือต้องวาดฉากใหม่
```

**2. ภาพนิ่ง**
```
บทผ่านแล้ว ทำภาพนิ่ง 3 ฉากตามสไตล์ N01 ให้ดู — ต้องมีฉากหลังหลายชั้น แสงจากดวงอาทิตย์หรือไฟ
ตัวละครมีข้อต่อและเงาที่พื้น ใส่ป้าย "ภาพประกอบ"
```

**3. เสียงและคลิปทดสอบ**
```
ภาพผ่าน ทำเสียงพากย์ ซับ ใส่เสียงบรรยากาศทุกฉากและเสียงปืนใหญ่ ธนู ดาบ จากคลังเสียงให้ตรงเฟรมที่ภาพเกิด
แล้วเรนเดอร์ 10 วินาทีแรกให้ดู
```

**4. ตัวเต็ม**
```
เรนเดอร์ตัวเต็ม พร้อมปก คำอธิบายคลิป และเครดิต
```

1. ศึกบางระจัน — ชาวบ้านตั้งค่ายสู้ทัพพม่า 8 ครั้ง
