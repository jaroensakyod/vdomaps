# คำสั่งสำหรับสไตล์ N23 ละครกระดาษ

**1. เรื่องและบท**
```

แบ่งเป็นการ์ดภาพ 4–6 ใบ บอกว่าแต่ละใบวาดอะไร ใครพูดประโยคไหน และใบไหนควรดึงครึ่งเดียวก่อนเฉลย
```

**2. ภาพนิ่ง**
```
บทผ่านแล้ว ทำภาพนิ่งการ์ด 3 ใบในกล่องไม้ตามสไตล์ N23 ให้ดู สีโปสเตอร์ทึบแบบกวอช ตัวละครแต่ละตัวใส่สีเดียวกันทุกใบ
มีป้ายกระดาษห้อยใต้กล่องบอกว่าใครพูดอะไร
```

**3. เสียงและคลิปทดสอบ**
```

**4. ตัวเต็ม**
```
