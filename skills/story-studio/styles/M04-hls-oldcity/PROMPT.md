# คำสั่งสำหรับสไตล์ M04 ฟิล์มลาดตระเวน

ก๊อปทีละข้อไปวางในผู้ช่วย AI (Claude Code / Codex) แล้วเปลี่ยนข้อความใน [ ]

**1. เรื่องและบท**
```
ใช้สไตล์ M04 ฟิล์มลาดตระเวน ทำคลิปเรื่อง [เกาะเมืองอยุธยามองจากอวกาศ] ยาว [60 วินาที] แนว[ตั้ง] — หาข้อมูล เขียนบทให้ดูก่อน
ระบุพิกัดวัด วัง ป้อม ที่จะวงดินสอเขียนเลขกำกับ และกรอบภาพดาวเทียมที่ต้องดึง
```

**2. ภาพนิ่ง**
```
บทผ่านแล้ว ดึงภาพ HLS วันที่ฟ้าโปร่งช่วงหน้าแล้ง ตามหัวข้อ Data ใน STYLE.md ของ M04 ทำภาพนิ่ง 3 ฉากให้ดู
เป็นฟิล์มขาวดำเขียวเทาบนกล่องไฟ มีรูหนามเตย ป้ายแฟ้มพิมพ์ดีดตราลับ และวงดินสอสีของนักวิเคราะห์
(ภาพจากอวกาศ, ซูมถึงเมือง, วงเป้าหมายครบ)
```

**3. เสียงและคลิปทดสอบ**
```
ภาพผ่าน ทำเสียงพากย์ ซับ ให้วงดินสอและชื่อลายมือขึ้นตรงคำที่พูดชื่อสถานที่ เลขภาพบนขอบฟิล์มเปลี่ยนทุกครั้งที่ภาพคมขึ้น แล้วเรนเดอร์ 10 วินาทีแรกให้ดู
```

**4. ตัวเต็ม**
```
เรนเดอร์ตัวเต็ม ทั้งแนวตั้งและแนวนอน พร้อมปก คำอธิบายคลิป และเครดิตภาพดาวเทียม NASA / OpenStreetMap
```

## ตัวอย่างเรื่องที่เหมาะ

1. เกาะเมืองอยุธยา — ทำไมแม่น้ำสามสายทำให้ตีไม่แตกมา 400 ปี
2. เมืองโบราณศรีเทพจากอวกาศ — คูน้ำคันดินที่ยังเห็นได้ถึงวันนี้
3. กรุงธนบุรี — ป้อมวิไชยประสิทธิ์กับปากคลองบางกอกใหญ่
