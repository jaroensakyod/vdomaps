# คำสั่งสำหรับสไตล์ N10 ฉากวังและพระนคร (ลายรดน้ำ)

ก๊อปทีละข้อไปวางในผู้ช่วย AI (Claude Code / Codex) แล้วเปลี่ยนข้อความใน [ ]

**1. เรื่องและบท**
```
ใช้สไตล์ N10 ฉากวังและพระนคร (ลายรดน้ำ) ทำคลิปเรื่อง [การย้ายราชธานีมาบางกอก พ.ศ. 2325] ยาว [90 วินาที] แนวตั้ง —
หาข้อมูล เขียนบทให้ดูก่อน แบ่งเป็นฉากละ 3–4 วินาที และบอกว่าแต่ละฉากใช้ลายไหนใน kit
(ปรางค์ พระที่นั่ง กำแพง เรือพระที่นั่ง ขุนนาง พระสงฆ์ ไฟลายกนก)
```

**2. ภาพนิ่ง**
```
บทผ่านแล้ว ทำภาพนิ่ง 3 ฉากตามสไตล์ N10 ให้ดู — ลายทองบนพื้นรักดำในกรอบตู้ลายรดน้ำ ขอบชาดแดง
ในฉากมีแค่ทองกับเส้นดำเท่านั้น มีป้าย "ภาพประกอบ"
```

**3. เสียงและคลิปทดสอบ**
```
ภาพผ่าน ทำเสียงพากย์ ซับ ให้แต่ละฉากค่อย ๆ "รดน้ำ" ให้ทองปรากฏจากบนลงล่าง ใส่เสียงบรรยากาศ (ลม ฝูงชน ไฟ ฆ้อง)
จากคลังเสียงให้เบากว่าเสียงพากย์ แล้วเรนเดอร์ 10 วินาทีแรกให้ดู
```

**4. ตัวเต็ม**
```
เรนเดอร์ตัวเต็ม พร้อมปก คำอธิบายคลิป และเครดิต
```

## ตัวอย่างเรื่องที่เหมาะ

1. สร้างกรุงรัตนโกสินทร์ — ย้ายพระนครข้ามฟากแม่น้ำ ตั้งเสาหลักเมือง
2. พระราชพิธีบรมราชาภิเษก — ขบวนเรือ ท้องพระโรง ขุนนางเข้าเฝ้า
3. ชีวิตในวังหลวงกรุงศรีอยุธยา — วัด ตลาดน้ำ และกำแพงพระนคร
