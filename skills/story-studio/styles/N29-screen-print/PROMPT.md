**1. เรื่องและบท**
```

เขียนบทให้ดูก่อน บอกด้วยว่าแต่ละฉากเป็นโปสเตอร์แผ่นไหน ใช้หมึกกี่สี และพิมพ์ข้อความอะไรในแต่ละรอบปาด
```

**2. ภาพนิ่ง**
```

ให้เห็นหมึกทับกันเป็นสีใหม่ และขอบหมึกหนา
```

```

```

**4. ตัวเต็ม**
