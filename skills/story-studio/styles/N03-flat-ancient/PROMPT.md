# คำสั่งสำหรับสไตล์ N03 ภาพเขียนแดงบนไห

ก๊อปทีละข้อไปวางในผู้ช่วย AI (Claude Code / Codex) แล้วเปลี่ยนข้อความใน [ ]

**1. เรื่องและบท**
```
ใช้สไตล์ N03 ภาพเขียนแดงบนไห ทำคลิปเรื่อง [ฮันนิบาลพาช้างข้ามเทือกเขาแอลป์] ยาว [60 วินาที] แนวตั้ง
— หาข้อมูล เขียนบทให้ดูก่อน บอกตัวเลขเด่นของแต่ละช่วงสำหรับคอไห และแต่ละฉากรอบไหมีภาพอะไร
```

**2. ภาพนิ่ง**
```
บทผ่านแล้ว ทำภาพนิ่ง 3 ฉากตามสไตล์ N03 ให้ดู ตัวละครเป็นสีดินเผาบนพื้นเคลือบดำ ลายเส้นดำบาง หันข้างตรง
ฝ่ายไหนยังไม่มีให้เปลี่ยนลายบนโล่หรือหมวก
```

**3. เสียงและคลิปทดสอบ**
```
ภาพผ่าน ทำเสียงพากย์ ซับ ใส่เสียงช้าง แตรศึก ดาบปะทะจากคลังเสียงตรงจังหวะภาพ ให้ไหหมุนไปฉากถัดไป
ตอนเปลี่ยนประโยค แล้วเรนเดอร์ 10 วินาทีแรกให้ดู
```

**4. ตัวเต็ม**
```
เรนเดอร์ตัวเต็ม พร้อมปก คำอธิบายคลิป และเครดิต
```

**ใช้เป็นภาพประกอบบนแผนที่**
```
ในตอนนี้ ใส่ภาพแถบไหแบบ N03 ในกรอบบนแผนที่ ช่วง [ch4] ทุกประโยค ชี้ไปที่สมรภูมิที่พูดถึง
```
