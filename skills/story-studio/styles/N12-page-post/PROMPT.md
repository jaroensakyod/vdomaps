**1. เรื่องและข้อความโพสต์**
```

[ยุทธนาวีเกาะช้าง] — หาข้อมูล เขียนชื่อบนดวงแสตมป์ หัวโพสต์ 2 บรรทัด (คำถามท้ายเป็นสีแดงชาด)
และแคปชันโพสต์พร้อมแฮชแท็กให้ดูก่อน
```

**2. ภาพนิ่ง**
```

(เขียว น้ำเงิน แดงชาด) เป็นรูป [เรือรบกลางทะเลยามเย็น] (หรือใช้รูปของเพจเอง [public/my-photo.jpg])
แสตมป์ดวงเล็กเป็นแผนที่ [อ่าวไทย] มาร์กจุด [เกาะช้าง] และตราประทับวันที่ [17 ม.ค.]
```

**3. ทีเซอร์สั้น**
```
ภาพผ่าน ทำเป็นคลิปทีเซอร์ 8 วินาทีจากภาพเดียวกัน ให้แสตมป์เลื่อนมาวางทีละดวง ตราประทับกระแทกลง
แล้วข้อความทยอยขึ้น ใส่เสียงเบา ๆ แล้วเรนเดอร์ภาพนิ่งเฟรมสุดท้ายให้ดูก่อน
```
