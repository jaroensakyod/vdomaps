# คำสั่งสำหรับสไตล์ M25 แผนที่โมเสก

ก๊อปทีละข้อไปวางในผู้ช่วย AI (Claude Code / Codex) แล้วเปลี่ยนข้อความใน [ ]

**1. เรื่องและบท**
```
ใช้สไตล์ M25 แผนที่โมเสก ทำคลิปเรื่อง [เส้นทางสายไหมทางทะเล] ยาว [45 วินาที] แนวตั้ง — หาข้อมูลพร้อมแหล่งอ้างอิง
เขียนบทให้ดูก่อน บอกด้วยว่าแต่ละช่วงจะปูเส้นทางไหน จากเมืองไหนไปเมืองไหน และเมืองศูนย์กลางที่โมเสกเริ่มปูคือที่ไหน
```

**2. ภาพนิ่ง**
```
บทผ่านแล้ว ทำภาพนิ่ง 3 ภาพตามสไตล์ M25: ตอนวาดลายเส้นบนพื้นปูน ตอนหินกำลังปู และตอนปูเส้นทางเสร็จ
ใส่ป้ายหินอ่อนชื่อเมือง (ไทย + ละติน/อังกฤษ) และคำว่า "แนวเส้นทางโดยประมาณ"
```

**3. เสียงและคลิปทดสอบ**
```
ภาพผ่าน ทำเสียงพากย์ ซับ ใส่เสียงหินกระทบตอนปูเมือง และเสียงลมเบา ๆ จากคลังเสียง แล้วเรนเดอร์ 10 วินาทีแรกให้ดู
```

**4. ตัวเต็ม**
```
เรนเดอร์ตัวเต็ม พร้อมปก คำอธิบายคลิป และเครดิตแผนที่กับแหล่งข้อมูล
```

## ตัวอย่างเรื่องที่เหมาะ

1. ถนนโรมันสามสายแรก — วีอาอัปปีอา ฟลามีเนีย เอมีเลีย (ตัวอย่างในเดโม)
2. เมืองท่าบนเส้นทางเครื่องเทศ — จากอเล็กซานเดรียถึงมุซีริส
3. อาณาจักรโรมันยุคทราจัน ค.ศ. 117 — ปูแผ่นดินจังหวัดต่อจังหวัด (เขตแดนโดยประมาณ)
