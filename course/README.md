# ชุดสอน — คลาส 1 ชั่วโมง "ทำคลิปแผนที่เล่าเรื่องด้วย Claude"

สำหรับครู: ส่งอะไรให้นักเรียน และสอนตามเวลาอย่างไร

## ไฟล์ในโฟลเดอร์นี้

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `STUDENT.md` | คู่มือนักเรียน: ลงแอป → รันตัวติดตั้ง → ใส่ key → เช็กเครื่อง |
| `PROMPTS.md` | คำสั่งให้ Claude ทีละขั้น ใช้ในคลาส |
| `install-windows.ps1` / `.bat` | ตัวติดตั้ง Windows (เลือกโหมดการ์ดจอเอง: NVIDIA/Intel/AMD/ไม่มีการ์ด) |
| `install-mac.sh` | ตัวติดตั้ง Mac (Apple Silicon และ Intel) |
| `env.example` | ต้นแบบไฟล์ `.env` ที่นักเรียนใส่ Gemini API key — ตัวติดตั้งก๊อปให้อัตโนมัติ |
| `CLAUDE.md` | คำสั่งประจำโปรเจกต์ที่ตัวติดตั้งวางไว้ในโฟลเดอร์นักเรียน ให้ Claude รู้ว่าต้องทำอะไร พูดไทย สอนมือใหม่ |

สไลด์สอนอยู่ใน Claude (ลิงก์ที่ครูได้รับ) ดาวน์โหลดเป็น PowerPoint / PDF ได้

## ส่งให้นักเรียน (3–7 วันก่อนเรียน)

ส่งลิงก์คู่มือเดียวพอ — ในคู่มือมีคำสั่งติดตั้งครบทั้ง Windows และ Mac:

> 📍 เตรียมเครื่องก่อนเรียน (20–40 นาที) ทำตามนี้:
> https://github.com/jaroensakyod/vdomaps/blob/main/course/STUDENT.md
> ต้องมี Claude Pro/Max + บัญชี Google · เสร็จแล้วแคปภาพแผนที่ทดสอบส่งในกลุ่มด้วยนะครับ

แนบ `install-windows.bat` ไปด้วยก็ได้ สำหรับคนที่ไม่อยากเปิด PowerShell

**ให้นักเรียนส่งภาพ `out/test.png` ในกลุ่มก่อนวันเรียน** — ใครยังไม่ส่ง ตามแก้ก่อน คลาส 1 ชั่วโมงไม่พอสำหรับติดตั้งสด

## ตารางสอน 60 นาที

| นาที | ช่วง | ทำอะไร |
|---|---|---|
| 0–5 | เปิด | โชว์คลิปตัวอย่าง (worldnews / thaihistory) · ไอเดีย: ทุกเฟรมวาดด้วยโค้ดจากข้อมูลแผนที่เปิด |
| 5–10 | เช็กเครื่อง | ทุกคนเปิด Claude → Code → `my-channel` → พรอมต์ข้อ 0 |
| 10–17 | เข้าใจระบบ | 8 ขั้น 3 ด่านอนุมัติ · Claude = ทีมผลิต เรา = บรรณาธิการ · กฎลิขสิทธิ์แผนที่ |
| 17–27 | ลงมือ 1 | พรอมต์ข้อ 1: เลือกเรื่อง → บท → แก้บท → อนุมัติ · สอนเขียน hook 3 วินาทีแรก |
| 27–37 | ลงมือ 2 | พรอมต์ข้อ 2: ภาพนิ่ง 3 ฉาก → ติชม → อนุมัติ |
| 37–47 | ลงมือ 3 | พรอมต์ข้อ 3–4: เสียงพากย์ + ซับ + เรนเดอร์ 10 วินาที (ระหว่างรอ อธิบายมาตรฐานสไตล์ข่าว) |
| 47–55 | ลงมือ 4 | พรอมต์ข้อ 5: เรนเดอร์จริง · ดูไฟล์ใน `out/` · คำบรรยาย + เครดิต |
| 55–60 | ปิด | การบ้าน: ทำอีก 1 คลิปเรื่องของตัวเอง · ล็อกสไตล์ช่อง · ถาม-ตอบ |

เครื่องช้า (ไม่มีการ์ดจอ) อาจเรนเดอร์ไม่ทันในคลาส — ให้ทำถึงข้อ 4 แล้วสั่งข้อ 5 ทิ้งไว้ที่บ้าน

## ปัญหาที่เจอบ่อย

| อาการ | แก้ |
|---|---|
| ไม่พบ winget (Windows 10 รุ่นเก่า) | Microsoft Store → ค้น "App Installer" → Update แล้วรันใหม่ |
| ลงเสร็จแต่พิมพ์ `node` ไม่เจอ | ปิด PowerShell/Terminal เปิดใหม่ แล้วรันตัวติดตั้งซ้ำ (รันซ้ำได้ ไม่ลบงาน) |
| Windows ชื่อผู้ใช้ภาษาไทย / path ยาว | ตัวติดตั้งใช้ `C:\maps` อยู่แล้ว ไม่ต้องแก้ |
| เสียงพากย์ error 429 / quota | key ฟรีมีโควตารายวัน รอวันถัดไป หรือเปิด billing ใน AI Studio |
| Claude ขอให้วาง key ในแชต | ไม่ต้อง — เปิด `.env` วาง key แล้ว Save บอก Claude ว่า "ใส่ใน .env แล้ว" |
| whisper โหลดนาน | โหลดโมเดลครั้งเดียว ~1.5 GB ให้ทำข้อ 3 ที่บ้านก่อนได้ |
