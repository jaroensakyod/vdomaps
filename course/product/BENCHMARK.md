## จุดที่เขาเก่ง และเราต้องทำให้ได้อย่างน้อยเท่า

1. ระบบทำให้แต่ละช่องหน้าตาไม่ซ้ำกัน
2. กฎจังหวะที่เป็นตัวเลข อ้างอิงจากคลิปจริง
3. คลิปยาวหลายภาษาครบวงจร พร้อมขั้นตอนอัปโหลดเสียงหลายภาษาของ YouTube
4. คู่มือเล่าเรื่องตามนิช และข้อมูลนิชตามรายได้โฆษณา
5. ใส่ภาพถ่ายจริงจาก Wikimedia Commons ได้อย่างถูกลิขสิทธิ์

## ระบบใหม่ที่ต้องสร้าง (คิดเอง ไม่ลอก)

**ลายเซ็นช่อง (Channel Signature)** — ตอบโจทย์ "สไตล์คล้ายกันหมด" ให้ดีกว่า Design DNA:

1. **6 แกนออกแบบ** ที่ทุกสไตล์ต้องระบุ: พื้น (ภาพจริง / วาด / กระดาษ / เวที / ภาพพิมพ์), สี 5 สี, เส้น, ตัวอักษร, การเคลื่อนไหว, และ **กรอบเล่า** (การ์ดข่าว / หน้าหนังสือ / เวที / จอเกมโชว์ / แฟ้มเอกสาร ฯลฯ)
2. **ตัวตรวจจากภาพจริง** `npm run distinct`: เรนเดอร์ภาพปกของทุกสไตล์ แล้ววัดความต่างจริงด้วย 3 อย่าง คือ สีโดยรวม, ความหนาแน่นของเส้น, และตำแหน่งกล่อง/ตัวอักษรบนจอ ถ้าคู่ไหนใกล้กันเกินเกณฑ์จะไม่ผ่าน ใช้ตรวจทั้งสไตล์ในเล่ม และหน้าตาช่องของผู้ซื้อแต่ละคน
3. **ผู้ซื้อเลือกเอง ไม่ใช่สุ่ม**: ผู้ช่วย AI เสนอ 3 ทางที่ต่างกันจริง (ผ่านตัวตรวจ) ให้ผู้ซื้อเลือก แล้วล็อกไว้ใน `project/style.json`

## เกณฑ์คุณภาพก่อนวางขาย (ต้องผ่านทุกข้อ)

- [ ] ทุกสไตล์ผ่าน `npm run distinct` กับทุกสไตล์อื่นในเล่ม
- [ ] ทุกสไตล์มีคลิปตัวอย่าง 15 วิ **มีเสียงจริง** (ต้องปิด Smart App Control หรือเรนเดอร์บนเครื่องอื่น)
- [ ] ติดตั้งบนเครื่องเปล่า Windows + Mac แล้วได้ภาพแรกใน 30 นาที
- [ ] ผู้ช่วย AI ทำคลิป 45 วิ ตามคำสั่งใน `PROMPT.md` ได้ครบ 3 จุดอนุมัติ โดยไม่ต้องแก้มือ
- [ ] ไม่มีข้อความ โค้ด ข้อมูล หรือชื่อสไตล์ที่มาจากชุดของคู่แข่ง
