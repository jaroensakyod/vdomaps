# Story Studio Premium — สอนตัวต่อตัว

ขอบคุณที่เลือกชุด Premium ชุดนี้มีการสอนตัวต่อตัว เพื่อพาคุณตั้งช่องจนได้คลิปแรกที่ลงจริง

## สิ่งที่ทำด้วยกัน

1. **ตั้งเครื่อง** ติดตั้งให้ผ่านบนเครื่องของคุณ (การ์ดจอ, Whisper, Smart App Control ถ้าเจอ)
2. **เลือกนิชและสไตล์** จากทั้ง 72 สไตล์ ดูว่าเรื่องแบบไหนเหมาะกับช่องคุณ
3. **ลายเซ็นช่อง** สร้างหน้าตาช่องของคุณเอง ให้ผ่าน `npm run distinct`
4. **คลิปแรก** ทำด้วยกันตั้งแต่บท ภาพนิ่ง เสียง จนเรนเดอร์ และตรวจก่อนอัปโหลด
5. **แผนซีรีส์** วางแผน 10 ตอนแรกและตารางลงคลิป

- ช่องทาง: [กรอก เช่น Zoom / Google Meet]
- วิธีนัด: [กรอก เช่น ส่งอีเมลหรือ LINE พร้อมเลขคำสั่งซื้อ]
- ใช้สิทธิ์ภายใน: [กรอก เช่น 90 วันหลังซื้อ]

## เตรียมก่อนนัดครั้งแรก

- รันตัวติดตั้งให้จบ (ถ้าติดตรงไหน ไม่เป็นไร เราแก้ด้วยกันในนัดแรก)
- ขอ Gemini API key ไว้ แต่ **ห้ามส่ง key ให้ผู้สอน** วางในไฟล์ `.env` ของคุณเองเท่านั้น
- คิดหัวข้อช่องไว้ 2–3 ทาง
