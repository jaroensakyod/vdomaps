# Story Studio — เริ่มใช้งาน

## ต้องมี

- Windows 10/11 หรือ Mac · พื้นที่ว่างประมาณ 10 GB · อินเทอร์เน็ตที่เสถียร
- ผู้ช่วย AI ตัวใดตัวหนึ่ง: **Claude Code** (บัญชี Claude Pro หรือ Max) หรือ **Codex** (บัญชี ChatGPT)
- บัญชี Google สำหรับขอ Gemini API key ฟรี (ใช้ทำเสียงพากย์)

## ติดตั้ง (ครั้งเดียว 20–40 นาที)

1. แตกไฟล์ zip ไว้ที่ไหนก็ได้ ให้ไฟล์ติดตั้งอยู่ข้างโฟลเดอร์ `story-studio`
2. **Windows:** ดับเบิลคลิก `install-windows.bat`
   (ถ้าขึ้น "Windows protected your PC" ให้กด *More info* แล้วกด *Run anyway*)
   **Mac:** เปิด Terminal พิมพ์ `bash ` (มีเว้นวรรคท้าย) แล้วลากไฟล์ `install-mac.sh` มาวาง กด Enter
3. ตัวติดตั้งจะถามว่าใช้ Claude Code หรือ Codex แล้วจัดการให้ทั้งหมด จากนั้นจะเปิดไฟล์ `.env` ขึ้นมา
   ให้วาง Gemini key ต่อจาก `GEMINI_API_KEY=` แล้วกด Save
4. เปิดโฟลเดอร์งาน (Windows `C:\maps\my-channel` · Mac `~/maps/my-channel`) ด้วยผู้ช่วย AI แล้วพิมพ์ว่า
   `เช็กว่าเครื่องพร้อมทำคลิปไหม`

## เริ่มทำคลิปแรก

เปิด `story-studio/styles/INDEX.md` เลือกสไตล์ที่ชอบ แล้วก๊อปคำสั่งจาก `PROMPT.md` ของสไตล์นั้นไปวาง เช่น

```
ใช้สไตล์ N05 หนังใหญ่ ทำคลิปเรื่องศึกบางระจัน ยาว 45 วินาที แนวตั้ง — หาข้อมูล เขียนบทให้ดูก่อน
```

ผู้ช่วย AI จะหยุดให้คุณอนุมัติ 3 ครั้ง คือ บท ภาพนิ่ง และคลิปตัวเต็ม

## ปัญหาที่เจอบ่อย

| อาการ | แก้ |
|---|---|
| ตัวติดตั้งบอกว่า Smart App Control บล็อกตัวเข้ารหัสวิดีโอ (ทำภาพนิ่งได้ แต่เรนเดอร์คลิปไม่ได้) | Windows Security → App & browser control → Smart App control → Off แล้วรันตัวติดตั้งซ้ำ (ปิดแล้วเปิดคืนไม่ได้ถ้าไม่ล้างเครื่อง) |
| ลงเสร็จแต่พิมพ์ `node` ไม่เจอ | ปิดหน้าต่าง เปิดใหม่ แล้วรันตัวติดตั้งซ้ำ (รันซ้ำได้ ไม่ลบงาน) |
| เสียงพากย์ error 429 / quota | key ฟรีมีโควตารายวัน รอวันถัดไป หรือเปิด billing ใน Google AI Studio |

## ห้ามทำ

- ห้ามส่งไฟล์ `.env` ให้ใคร และห้ามวาง key ลงในแชต
- ห้ามแจกหรือขายต่อไฟล์ในชุดนี้ ส่วนคลิปที่ทำออกมาเป็นของคุณ ลงช่องและหารายได้ได้
