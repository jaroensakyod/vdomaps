# เสียง: พากย์ ซับ เสียงประกอบ

## เสียงพากย์

- ใช้ Gemini TTS ผ่านคำสั่ง `npm run tts -- <ชื่อตอน> <เสียง>` key ฟรีมีโควตารายวัน
- ตัวละครพูดได้ด้วยเสียงแยก กำหนดใน `voices.json`
- หลังพากย์: `npm run align -- <ตอน>` จับเวลาคำด้วย Whisper แล้ว `node scripts/snap-words.mjs <ตอน>`

## เสียงประกอบจริง

- คลังเสียงประจำชุดดาวน์โหลดเข้าเครื่องคุณด้วย `npm run sfx-lib` (มาจาก Mixkit และ Pixabay ใช้เชิงพาณิชย์ได้ ไม่ต้องให้เครดิต แต่ห้ามแจกไฟล์เสียงต่อ)
- ทุกเหตุการณ์ในภาพมีเสียงลงตรงเฟรม เช่น ปืน ระเบิด ม้า ประตู
- ทุกฉากมีเสียงบรรยากาศ (bed) เบา ๆ
- **เสียงพากย์ต้องชนะเสมอ** มิกซ์เสียงประกอบให้ต่ำตั้งแต่แรก

## ความดังและไฟล์ส่งมอบ

- `npm run loudness -- out/<ไฟล์>.mp4` ปรับความดังให้ตรงมาตรฐาน YouTube (−14 LUFS)
- `npm run srt -- <ตอน>` ซับสำหรับอัปโหลด
- `npm run thumb` ปก · `npm run describe -- <ตอน>` คำอธิบายคลิปพร้อมบทและเครดิต
