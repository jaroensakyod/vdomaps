# ช่องเล่าเรื่องที่ไม่เหมือนใคร ด้วยผู้ช่วย AI

หนังสือเล่มนี้พาคุณทำคลิปเล่าเรื่องที่ **วาดด้วยโค้ดทุกเฟรม** ใช้ Claude Code หรือ Codex เป็นทีมผลิต
ส่วนคุณเป็นบรรณาธิการ คือเลือกเรื่อง อนุมัติบท และดูภาพก่อนเรนเดอร์จริงทุกครั้ง

## ทำไมต้องวาดด้วยโค้ด

- **ไม่มีภาพจาก AI สร้างรูป** ภาพทุกภาพเขียนเป็นโค้ด จึงไม่มีมือหกนิ้ว หน้าเพี้ยน หรือภาพที่ดูเหมือนช่องอื่น
- **ไม่ติดลิขสิทธิ์แผนที่** แผนที่มาจากข้อมูลเปิด เช่น Natural Earth, OpenStreetMap และภาพดาวเทียม NASA พร้อมเครดิตที่ถูกต้อง
- **แก้ได้ทุกจุด** อยากเปลี่ยนสี เปลี่ยนคำ หรือเลื่อนจังหวะ ก็สั่งผู้ช่วย AI แล้วเรนเดอร์ใหม่ ไม่ต้องวาดใหม่ทั้งฉาก
- **ได้ทั้งแนวตั้งและแนวนอน** จากโค้ดชุดเดียว ทั้ง Shorts / Reels 9:16 และคลิปยาว 16:9

## ในชุดนี้มีอะไร

| ของในชุด | ใช้ทำอะไร |
|---|---|
| Skill `story-studio` | คู่มือที่ผู้ช่วย AI อ่านแล้วทำงานตามขั้นตอน หยุดให้คุณอนุมัติ 3 ครั้ง |
| แพ็กสไตล์ | แต่ละสไตล์มีโค้ดสำเร็จ (`Demo.tsx` + `kit/`) การ์ดสไตล์ คำสั่งภาษาไทย และภาพปก |
| โปรเจกต์ Remotion | เครื่องมือพากย์เสียง จับเวลาคำ ซับ เสียงประกอบ ปก คำอธิบายคลิป |
| ตัวติดตั้ง | ดับเบิลคลิกครั้งเดียว ลงเครื่องมือ สร้างโฟลเดอร์งาน ทดสอบเรนเดอร์ |
| ตัวตรวจ `npm run distinct` | วัดว่าหน้าตาช่องของคุณต่างจากสไตล์อื่นจริงไหม |

## วิธีอ่านเล่มนี้

อ่านบทที่ 2–5 ให้จบก่อนทำคลิปแรก จากนั้นเปิดหน้าสไตล์ที่ชอบ ก๊อปคำสั่งในกล่องไปวางในผู้ช่วย AI
แล้วทำตามที่มันถาม ใช้เวลาครั้งแรกราว 1–2 ชั่วโมงต่อคลิปสั้น
