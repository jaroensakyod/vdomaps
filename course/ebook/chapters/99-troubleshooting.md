# แก้ปัญหาที่เจอบ่อย

| อาการ | แก้ |
|---|---|
| ทำภาพนิ่งได้ แต่เรนเดอร์คลิปไม่ได้ (Windows 11) | Smart App Control บล็อกอยู่ ดูบทที่ 2 |
| ลงเสร็จแต่พิมพ์ `node` ไม่เจอ | ปิดหน้าต่าง เปิดใหม่ แล้วรันตัวติดตั้งซ้ำ (รันซ้ำได้ ไม่ลบงาน) |
| เสียงพากย์ error 429 / quota | key ฟรีมีโควตารายวัน รอวันถัดไป หรือเปิด billing ใน Google AI Studio |
| ผู้ช่วย AI ขอให้วาง key ในแชต | ไม่ต้อง เปิด `.env` วาง key แล้ว Save บอกว่า "ใส่ใน .env แล้ว" |
| Whisper โหลดนาน | โหลดโมเดลครั้งเดียว ราว 1.5 GB |
| ซับไม่ตรงปาก | สั่ง "รัน snap-words ใหม่" และเช็กว่าคำบนจอกับคำพากย์นับคำเท่ากัน |
| คำต้นประโยคหายจากเสียงพากย์ | สั่ง "เช็กคำที่ Whisper ได้ยิน แล้วพากย์ช่วงที่คำหายใหม่" |
| ภาพกระพริบระหว่างฉาก | ฉากต่อกันต้องซ้อนกันราว 14 เฟรม และเรนเดอร์ตัวจริงด้วย `--gl=angle` |
| path ยาว / ชื่อผู้ใช้ภาษาไทยบน Windows | ใช้โฟลเดอร์ `C:\maps` ตามตัวติดตั้ง |

## คำสั่งที่ใช้บ่อย

```
npm run style -- list          ดูสไตล์ในชุด
npm run style -- <ID> --lock   ติดตั้งสไตล์และล็อกสี
npm run gallery -- <ID>        ทำภาพปกของสไตล์
npm run distinct -- --image <ภาพ>   ตรวจว่าหน้าตาช่องไม่ซ้ำ
npm run tts -- <ตอน> <เสียง>    พากย์เสียง
npm run align -- <ตอน>          จับเวลาคำ
npm run srt -- <ตอน>            ซับ
npm run describe -- <ตอน>       คำอธิบายคลิป
npm run loudness -- <ไฟล์>      ปรับความดัง
```
