# 8 ขั้น 3 ด่านอนุมัติ

ผู้ช่วย AI คือทีมผลิต คุณคือบรรณาธิการ ทุกคลิปเดินตาม 8 ขั้นนี้ และผู้ช่วย AI **ต้องหยุดรอคุณ** ที่ด่าน 1, 2 และ 3

| ขั้น | ใครทำ | ได้อะไร |
|---|---|---|
| 1. เลือกเรื่อง | คุณ | หัวข้อ ความยาว แนวตั้งหรือแนวนอน สไตล์ |
| 2. ค้นข้อมูล | ผู้ช่วย AI | `sources.md` ทุกข้อเท็จจริงพร้อมแหล่งอ้างอิงและระดับความแน่นอน |
| 3. เขียนบท | ผู้ช่วย AI | ตารางบท: คำพากย์ + สิ่งที่ขึ้นจอ · **ด่าน 1: อนุมัติบท** |
| 4. ภาพนิ่ง 3 ฉาก | ผู้ช่วย AI | ภาพ hook กลางเรื่อง และตอนจบ · **ด่าน 2: อนุมัติภาพ** |
| 5. เสียงพากย์ | ผู้ช่วย AI | Gemini TTS + จับเวลาคำด้วย Whisper + `snap-words` |
| 6. สร้างฉาก | ผู้ช่วย AI | ภาพเปลี่ยนตามคำพากย์ เสียงประกอบลงตรงจุด |
| 7. ทดสอบ 10 วินาที | ผู้ช่วย AI | ดูหน้าตาจริงก่อนเรนเดอร์ทั้งคลิป |
| 8. ตัวเต็ม | ผู้ช่วย AI | คลิป + ซับ `.srt` + ปก + คำอธิบายคลิปพร้อมเครดิต · **ด่าน 3: ตรวจก่อนอัปโหลด** |

ผู้ช่วย AI **ไม่อัปโหลดเอง** คุณเป็นคนอัปโหลดทุกครั้ง

## คำสั่ง 4 ขั้นที่ใช้กับทุกสไตล์

ทุกสไตล์มีไฟล์ `PROMPT.md` ภายในมีคำสั่ง 4 ข้อนี้ เปลี่ยนแค่ชื่อสไตล์กับเรื่อง

```
1. ใช้สไตล์ [ID] ทำคลิปเรื่อง [ชื่อเรื่อง] ยาว [45 วินาที] แนวตั้ง — หาข้อมูล เขียนบทให้ดูก่อน
2. บทผ่านแล้ว ทำภาพนิ่ง 3 ฉากตามสไตล์ [ID] ให้ดู
3. ภาพผ่าน ทำเสียงพากย์ ซับ แล้วเรนเดอร์ 10 วินาทีแรกให้ดู
4. เรนเดอร์ตัวเต็ม พร้อมปก คำอธิบายคลิป และเครดิต
```

## ติดตั้งโค้ดของสไตล์

```
npm run style -- list        ดูสไตล์ทั้งหมดในชุดของคุณ
npm run style -- N05         ติดตั้งโค้ดสไตล์ N05 ลงโปรเจกต์
npm run style -- N05 --lock  ติดตั้งและล็อกสีของช่อง
```

ผู้ช่วย AI รันคำสั่งเหล่านี้ให้เอง คุณไม่ต้องจำ
